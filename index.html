UNIT 1 – Mathematical Logic

1. Important symbols and meanings

ഓർമ്മിക്കുക: ¬ = അല്ല, ∧ = കൂടാതെ, ∨ = അല്ലെങ്കിൽ, → = ആണെങ്കിൽ, ↔ = അപ്പോൾ മാത്രം.

2. Main truth table

Shortcut: P → Q is false only for T → F. P ↔ Q is true when both values are same.

Implication-ൽ P ശരിയും Q തെറ്റും ആയാൽ മാത്രം answer False. Biconditional-ൽ രണ്ടും ഒരുപോലെ ആണെങ്കിൽ True.

3. Tautology, contradiction, contingency

Tautology: Always true. P ∨ ¬P = T

Contradiction: Always false. P ∧ ¬P = F

Contingency: Sometimes true and sometimes false. Example: P ∧ Q

എല്ലാ rows-ലും T = tautology. എല്ലാ rows-ലും F = contradiction. T, F രണ്ടും വരുന്നത് contingency.

ആദ്യം നാല് combinations എഴുതുക. P True, Q False ആയ row-യിൽ മാത്രം F എഴുതുക.

5. Logical equivalence laws

¬(¬P) = P
P ∧ T = P ; P ∨ F = P
P ∧ F = F ; P ∨ T = T
P ∧ P = P ; P ∨ P = P
P ∨ ¬P = T ; P ∧ ¬P = F
P → Q ≡ ¬P ∨ Q
P ↔ Q ≡ (P→Q) ∧ (Q→P)
¬(P∧Q) ≡ ¬P∨¬Q
¬(P∨Q) ≡ ¬P∧¬Q
ഈ formulas ഉപയോഗിച്ച് വലിയ logical expressions ചെറുതാക്കാം.

6. Solved: Simplify P → Q

Given: P → Q
Use implication law: P → Q = ¬P ∨ Q
Answer: ¬P ∨ Q
Arrow (→) മാറ്റി NOT P OR Q എന്ന് എഴുതുക.

7. Converse, inverse, contrapositive

Original: P → Q

Converse-ൽ സ്ഥാനം മാറ്റുക. Inverse-ൽ NOT ചേർക്കുക. Contrapositive-ൽ സ്ഥാനം മാറ്റിയും NOT ചേർത്തും എഴുതുക.

8. PDNF and PCNF – easy method

PDNF: Take rows where output is 1. Write each row as an AND term, then join terms using OR.

PCNF: Take rows where output is 0. Write each row as an OR term, then join terms using AND.

For variables P,Q:

PDNF = output 1 വരുന്ന rows. PCNF = output 0 വരുന്ന rows. 1-row-ൽ 0 ആണെങ്കിൽ variable-ന് NOT ഇടുക. 0-row maxterm-ൽ 1 ആണെങ്കിൽ NOT ഇടുക.

UNIT 2 – Relations

1. Cartesian product

A × B = {(a,b) : a∈A, b∈B}

Example: A={1,2}, B={x,y}

A×B = {(1,x),(1,y),(2,x),(2,y)}

Number of pairs: |A×B| = |A| × |B|.

A-യിലെ ഓരോ element-നെയും B-യിലെ ഓരോ element-നോടും pair ആക്കുക. രണ്ട് sets-ലുള്ള എണ്ണം multiply ചെയ്താൽ total pairs കിട്ടും.

2. Relation, domain and range

R is a subset of A × B

Example: R={(1,2),(1,3),(2,3)}

Domain = {1,2}; Range = {2,3}.

Ordered pair-കളിലെ ആദ്യത്തെ values domain. രണ്ടാമത്തെ values range. Duplicate ഉണ്ടെങ്കിൽ ഒരിക്കൽ മാത്രം എഴുതുക.

3. Properties of relations

PropertyRuleCheck
ReflexiveaRa for every aAll (a,a) must exist
SymmetricaRb ⇒ bRaReverse pair must exist
AntisymmetricaRb and bRa ⇒ a=bNo two-way pair for different values
TransitiveaRb and bRc ⇒ aRcRequired shortcut pair exists
Reflexive: (1,1), (2,2) പോലുള്ള self-pairs വേണം. Symmetric: (1,2) ഉണ്ടെങ്കിൽ (2,1) വേണം. Transitive: (1,2),(2,3) ഉണ്ടെങ്കിൽ (1,3) വേണം.

4. Solved: Check reflexive and symmetric

A={1,2}; R={(1,1),(2,2),(1,2),(2,1)}.

Reflexive: (1,1) and (2,2) are present. So reflexive.
Symmetric: (1,2) has reverse (2,1), and self-pairs reverse themselves. So symmetric.
Antisymmetric? No, because (1,2) and (2,1) exist while 1≠2.
Transitive: all required pairs are present. So transitive.
ഈ relation reflexive, symmetric, transitive ആണ്. അതിനാൽ equivalence relation ആണ്. Antisymmetric അല്ല.

5. Inverse of relation

R⁻¹ = {(b,a) : (a,b)∈R}

Example: R={(1,2),(2,3),(3,1)}

R⁻¹={(2,1),(3,2),(1,3)}
ഓരോ ordered pair-ലും സ്ഥാനം മാറ്റുക.

6. Composition of relations

If R is from A to B and S is from B to C, then S∘R contains (a,c) when there is a b such that aRb and bSc.

Example: R={(1,2),(2,3)}, S={(2,a),(3,b)}.

1 → 2 in R and 2 → a in S, so (1,a).
2 → 3 in R and 3 → b in S, so (2,b).
S∘R = {(1,a),(2,b)}
ആദ്യ relation-ൽ കിട്ടുന്ന middle value, രണ്ടാമത്തെ relation-ന്റെ ആദ്യ value-യുമായി match ചെയ്യുക.

7. Matrix representation

For A={1,2,3}, R={(1,1),(1,3),(2,2)}:

123
1101

Put 1 if pair exists; otherwise put 0.

Row = first element, column = second element. Pair ഉണ്ടെങ്കിൽ 1, ഇല്ലെങ്കിൽ 0.

8. Transitive closure

Example: R={(1,2),(2,3)}.

We have 1→2 and 2→3.
For transitivity, add 1→3.
R⁺ = {(1,2),(2,3),(1,3)}
a→b, b→c ഉണ്ടെങ്കിൽ a→c ചേർക്കുക. എല്ലാ ആവശ്യമായ pairs ചേർന്നാൽ transitive closure കിട്ടും.

UNIT 3 – Partial Ordering and Lattice

1. POSET formula

A set with a relation that is reflexive, antisymmetric and transitive is called a partially ordered set.

POSET = Reflexive + Antisymmetric + Transitive
ഈ മൂന്ന് properties ഒരുമിച്ച് ഉണ്ടായാൽ ആ set POSET ആണ്.

2. Divisibility relation – worked example

Set A={1,2,3,6}. Relation is “divides” (|).

Pairs:

R={(1,1),(1,2),(1,3),(1,6),(2,2),(2,6),(3,3),(3,6),(6,6)}
Reflexive: every number divides itself.
Antisymmetric: if a divides b and b divides a, then a=b.
Transitive: if a divides b and b divides c, then a divides c.

Therefore it is a POSET.

1,2,3,6 divisibility relation-ൽ ഈ മൂന്ന് rules ശരിയാണ്. അതിനാൽ POSET ആണ്.

3. Hasse diagram

For divisors of 6:

1 is bottom, 6 is top. Lines show cover relations.

Hasse diagram വരയ്ക്കുമ്പോൾ self-loop വരയ്ക്കേണ്ടതില്ല. Transitive ആയി മനസ്സിലാകുന്ന long edges ഒഴിവാക്കാം.

4. Comparable and incomparable

Two elements a,b are comparable if a≤b or b≤a. Otherwise they are incomparable.

In divisibility order, 2 and 3 are incomparable because 2 does not divide 3 and 3 does not divide 2.

ഒന്നിനെ മറ്റൊന്ന് divide ചെയ്യാൻ കഴിയാത്ത 2,3 പോലുള്ള pair incomparable ആണ്.

5. Upper bound, lower bound, LUB and GLB

For S={2,3} in divisors of 6:

Upper bound: an element divisible by both 2 and 3 → {6}.
Lower bound: a number that divides both 2 and 3 → {1}.
LUB(2,3)=6 ; GLB(2,3)=1
രണ്ടിനും മുകളിലുള്ള common value 6 ആണ്. രണ്ടിനെയും divide ചെയ്യുന്ന common value 1 ആണ്.

6. Lattice

A POSET is a lattice if every pair of elements has:

Join a∨b = LUB(a,b)
Meet a∧b = GLB(a,b)

For divisibility, join is LCM and meet is GCD.

Example: for 2 and 3, LCM=6 and GCD=1.

Lattice-ൽ ഓരോ pair-നും LUB, GLB ഉണ്ടായിരിക്കണം. Divisibility set-ൽ join = LCM, meet = GCD.

7. Important lattice laws

a∨a=a ; a∧a=a (Idempotent)
a∨b=b∨a ; a∧b=b∧a (Commutative)
(a∨b)∨c=a∨(b∨c) (Associative)
(a∧b)∧c=a∧(b∧c) (Associative)
a∨(a∧b)=a ; a∧(a∨b)=a (Absorption)
a∨(b∧c)=(a∨b)∧(a∨c) (Distributive)
ഈ law names-ഉം formulas-ഉം പരീക്ഷയ്ക്ക് ഓർമ്മിക്കുക. Join-ന് ∨, meet-ന് ∧ ഉപയോഗിക്കുന്നു.

8. Chain and distributive lattice

Chain: Every pair of elements is comparable.

Distributive lattice: Both distributive laws hold:

a∧(b∨c)=(a∧b)∨(a∧c)
a∨(b∧c)=(a∨b)∧(a∨c)
ഒരു set-ലെ എല്ലാ pairs-ഉം compare ചെയ്യാൻ കഴിയുന്നുവെങ്കിൽ chain. Distributive law ശരിയായാൽ distributive lattice.

UNIT 4 – Boolean Algebra and K-Map

1. Basic operations

OperationSymbolMeaning
ORA+B1 if any input is 1
ANDAB1 only if both are 1
NOTA′Opposite value
Boolean algebra-ൽ 0,1 മാത്രമാണ്. + എന്നത് OR; multiplication/dot എന്നത് AND; apostrophe എന്നത് NOT.

2. Boolean laws – full formula list

Identity: A+0=A ; A·1=A
Null: A+1=1 ; A·0=0
Idempotent: A+A=A ; A·A=A
Complement: A+A′=1 ; A·A′=0
Involution: (A′)′=A
Commutative: A+B=B+A ; AB=BA
Associative: (A+B)+C=A+(B+C)
Distributive: A(B+C)=AB+AC
Absorption: A+AB=A ; A(A+B)=A
De Morgan: (A+B)′=A′B′ ; (AB)′=A′+B′
ഇവയാണ് Boolean expression simplify ചെയ്യാൻ പ്രധാനമായി ഉപയോഗിക്കുന്ന laws.

3. De Morgan theorem – truth table proof

AB(A+B)′A′B′(AB)′A′+B′
001111

Both sides match, so both theorems are proved.

ഓരോ row-ലും ഇടത് side, വലത് side ഒരേ answer ആണ്. അതിനാൽ theorem prove ചെയ്തു.

4. SOP and POS

SOP (Sum of Products): OR of AND terms.

F=AB+A′C

POS (Product of Sums): AND of OR terms.

F=(A+B)(A′+C)
SOP = AND terms-നെ OR കൊണ്ട് കൂട്ടുക. POS = OR terms-നെ AND കൊണ്ട് ഗുണിക്കുക.

5. Solved simplification problems

Example 1: F=A+AB

F=A(1+B)
1+B=1
F=A×1=A

Example 2: F=AB+AB′

F=A(B+B′)
B+B′=1
F=A×1=A

Example 3: F=(A+B)(A+B′)

Use (X+Y)(X+Z)=X+YZ
F=A+BB′
BB′=0
F=A
Common variable പുറത്തെടുക്കുക. Complement pair (B+B′) = 1, (BB′)=0 എന്ന് ഓർമ്മിക്കുക.

6. K-Map grouping rules

  • For SOP, group the 1s.
  • For POS, group the 0s.
  • Groups must contain 1, 2, 4, 8, … cells.
  • Make the largest possible groups.
  • Groups may wrap around the edges.
  • Diagonal cells are not adjacent.
  • Every required 1 (for SOP) must be covered.
SOP ആണെങ്കിൽ 1-കൾ group ചെയ്യുക. POS ആണെങ്കിൽ 0-കൾ group ചെയ്യുക. 1,2,4,8 എന്ന എണ്ണം മാത്രം. ഏറ്റവും വലിയ group ചെയ്യുക. Corner cells ചിലപ്പോൾ adjacent ആണ്.

7. Solved 2-variable K-Map

Given: F(A,B)=Σm(1,3)

A \\ B01
001

The two 1s are in the B=1 column.
A changes from 0 to 1, so remove A.

B column-ൽ രണ്ട് 1 ഉണ്ട്. A മാറുന്നു, അതിനാൽ A ഒഴിവാക്കുക. B സ്ഥിരമാണ്, അതിനാൽ final answer B.

8. Solved 3-variable K-Map

Given: F(A,B,C)=Σm(1,3,5,7).

Binary minterms: 001, 011, 101, 111. In all four, C=1.

Group all four 1s together.
A and B change; C remains 1.
Final answer: F=C
നാല് minterms-ലും C=1 ആണ്. A, B മാറുന്നു. അതിനാൽ അവ ഒഴിവാക്കി C മാത്രം എഴുതുക.

UNIT 5 – Finite Automata

1. Five components of finite automaton

M=(Q, Σ, δ, q₀, F)
SymbolMeaning
QSet of states
ΣInput alphabet
δTransition function
q₀Initial state
FFinal states
Q states, Σ input letters, δ next-state rule, q₀ starting state, F accepting states.

2. DFA transition function

δ : Q × Σ → Q

For every state and input symbol, a DFA has exactly one next state.

DFA-യിൽ ഒരു state-ൽ നിന്ന് ഒരു input symbol വരുമ്പോൾ കൃത്യമായി ഒരു next state മാത്രം.

3. NFA transition function

δ : Q × Σ → 2^Q

An NFA may have zero, one or many next states for an input symbol. ε-NFA may also move without reading an input symbol.

NFA-യിൽ ഒരേ input-ന് ഒന്നിലധികം next states വരാം. ε transition-ൽ input വായിക്കാതെ state മാറാം.

4. DFA vs NFA

DFANFA
Exactly one next stateZero or more next states
No ε moveε move may be allowed
One path for an inputMany possible paths
One final path must end in final stateAccepted if at least one path ends in final state
DFA-യിൽ ഒരു വഴി. NFA-യിൽ പല വഴികൾ ഉണ്ടാകാം. NFA-യിലെ ഏതെങ്കിലും ഒരു വഴി final state-ൽ എത്തിയാൽ accept ചെയ്യും.

അവസാന digit 1 ആണെങ്കിൽ q1-ൽ അവസാനിക്കും, അതിനാൽ accept. അവസാന digit 0 ആണെങ്കിൽ q0, അതിനാൽ reject.

9. Language {ab, ba}

Alphabet {a,b}. Accept exactly the two strings “ab” and “ba”.

Stateab
→ q0q1q2
q1qdqf
q2qfqd
* qfqdqd
qdqdqd

qf is final; qd is dead/trap state.

Input ab: q0→q1→qf = accepted.
Input ba: q0→q2→qf = accepted.
Input aa: q0→q1→qd = rejected.
ആദ്യ letter a ആണെങ്കിൽ q1, b ആണെങ്കിൽ q2. രണ്ടാമത്തെ letter opposite ആയാൽ final qf. തെറ്റായ letter വന്നാൽ trap state qd.

10. Important terms

Initial state: starting state. Final state: accepting state. Transition: movement between states. Trap state: dead non-final state. Accepted string: after reading all symbols, machine ends in a final state.

String മുഴുവൻ വായിച്ചതിന് ശേഷം final state-ൽ എത്തിയാൽ accept. Final state അല്ലെങ്കിൽ reject.

Accept if the complete input ends in a final state (for DFA); for NFA, at least one possible path ends in a final state.
