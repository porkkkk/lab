Set 1 — Permissions & Basic Linux

Shell script to list files with read, write, and execute permissions; date, calendar, and message.

Linux · Shell script

1. Display files with r, w, x permissions

Aim: List regular files for which the current user has read, write, and execute permission.

Save as set1.sh
#!/bin/bash
for file in *
do
    if [ -f "$file" ] && [ -r "$file" ] && [ -w "$file" ] && [ -x "$file" ]
    then
        echo "$file"
    fi
done
Run in Terminal
nano set1.sh

chmod +x set1.sh
./set1.sh

Memory: -r read, -w write, -x execute. No output means no matching file was found in the current directory.

Linux · Commands

2. Date, calendar, and message

Aim: Display the current date/time, calendar, and a message.

Type each line in Terminal
date
cal
echo "Welcome to Linux"

date shows date/time · cal shows the calendar (install a calendar utility if unavailable) · echo prints a message.

Set 2 — AWK & Windows Commands

Count characters, words, and lines; practise Windows file and directory operations.

Linux · AWK

1. Count characters, words, and lines

Aim: Count characters (excluding newline separators), words, and lines in a file.

Save as count.awk
{
    characters += length($0)
    words += NF
    lines++
}
END {
    print "Characters:", characters
    print "Words:", words
    print "Lines:", lines
}
Create sample and run
printf 'Hello World\nWelcome Linux\n' > sample.txt
awk -f count.awk sample.txt

For the sample text above: 23 characters (not counting newline separators), 4 words, 2 lines. NF is the number of fields/words in a line.

Windows · CMD

2. File and directory operations

Aim: Create, view, rename, and delete practice files and folders.

Run in Windows Command Prompt
dir
mkdir Test
cd Test
echo Hello > a.txt
type a.txt
ren a.txt b.txt
del b.txt
cd ..
rmdir Test

Run in order. mkdir makes a folder, cd changes location, type displays text, ren renames, and del deletes the test file.

Set 3 — Sorting & Text Processing

Sort numbers in ascending order and practise common text commands.

Linux · Shell script

1. Sort three numbers ascending

Aim: Arrange three input numbers from smallest to largest.

Save as sort.sh
#!/bin/bash
echo "Enter three numbers:"
read a b c

if [ "$a" -le "$b" ] && [ "$a" -le "$c" ]; then
    first=$a
elif [ "$b" -le "$a" ] && [ "$b" -le "$c" ]; then
    first=$b
else
    first=$c
fi

if [ "$a" -ge "$b" ] && [ "$a" -ge "$c" ]; then
    last=$a
elif [ "$b" -ge "$a" ] && [ "$b" -ge "$c" ]; then
    last=$b
else
    last=$c
fi

middle=$((a + b + c - first - last))
echo "Ascending order: $first $middle $last"
Run
nano sort.sh

chmod +x sort.sh
./sort.sh

Example input 8 2 5 gives 2 5 8. Enter three integers separated by spaces.

Linux · Text commands

2. Process a sample text file

Aim: Use head, tail, sort, and grep.

Create file and run commands
printf 'apple\nbanana\napple\norange\n' > fruits.txt
head fruits.txt
tail fruits.txt
sort fruits.txt
grep "apple" fruits.txt

head shows first lines, tail last lines, sort sorts lines, and grep finds matching lines.

Set 4 — Process & File Processing

Demonstrate process management and file-processing commands.

Linux · Process management

1. Use ps, kill, nice, and time

Aim: Display and manage a test process.

Run carefully in Terminal
ps
sleep 100 &
ps

kill PID
nice -n 10 sleep 5
time ls

Replace PID with the real process ID number for your test sleep process. Do not type the letters PID literally. ps lists processes; kill sends a signal; nice adjusts scheduling niceness; time measures execution time.

Linux · File processing

2. Use cut, paste, uniq, and tr

Aim: Manipulate the contents of a sample text file.

Run in Terminal
printf 'apple\nbanana\napple\n' > fruits.txt
cut -c 1-3 fruits.txt
paste fruits.txt fruits.txt
sort fruits.txt | uniq
tr 'a-z' 'A-Z' < fruits.txt

cut selects characters, paste combines lines side by side, uniq removes adjacent duplicate lines (sorting first groups duplicates), and tr translates lowercase letters to uppercase.

Set 5 — Directories, Redirection & vi

Create a user-defined directory, list its contents, and edit a text file.

Linux · Shell script

1. Create a directory and display contents

Aim: Ask for a directory name, create it, create two files, and list contents.

Save as directory.sh
#!/bin/bash
echo "Enter directory name:"
read name
mkdir -p "$name"
cd "$name" || exit 1
touch file1.txt file2.txt
echo "Directory contents:"
ls
Run
nano directory.sh

chmod +x directory.sh
./directory.sh

Example: enter MyFolder. The script creates that folder in the current directory, adds two empty files, and lists them. Use a new folder name for each run or note that existing files/folders may be reused.

Linux · Redirection & vi

2. Redirection and vi editor

Aim: Redirect output to a file and create/edit a file using vi.

Redirection commands
echo "Hello Linux" > file.txt
echo "Welcome" >> file.txt
cat file.txt
cat < file.txt
Open vi editor
vi notes.txt


     
> creates/replaces file content; >> appends; < takes input from a file. In vi, press i to insert, then Esc and :wq to save and quit.
Exam format: Write Aim → Program/Commands → Execution → Output. Practise each command in the correct environment: Linux commands in Linux Terminal, Windows commands in Command Prompt.
