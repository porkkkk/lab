Fraud model steps
C C F S T E O

Collect → Clean → Features → Split → Train → Evaluate → Optimize

C — Collect transaction data
C — Clean missing and duplicate data
F — Find useful features
S — Split training and testing data
T — Train a model
E — Evaluate the model
O — Optimize and monitor
Facial recognition
C D A E M D L

Capture → Detect → Align → Extract → Match → Decide → Liveness

C — Capture the face
D — Detect the face in the image
A — Align the face
E — Extract facial features
M — Match the registered template
D — Decide whether to allow or reject
L — Check liveness
Account reputation
LOGIN · DEVICE · IP · FAILURES · PLACE · HISTORY

Ask: Is this a normal login, from a known device and place, with normal behaviour? More unusual signals can mean higher risk.

Keystroke recognition
HOLD · GAP · SPEED · RHYTHM

Dwell time means how long a key is held. Flight time means the interval between key events. Compare current typing with the registered pattern.

Bagging versus boosting
BAG = TOGETHER
BOOST = STEP BY STEP

Bagging trains models independently and combines their answers. Boosting trains models one after another, focusing on earlier errors.

MFA categories
KNOW + HAVE + ARE

Know = password or PIN. Have = phone or token. Are = fingerprint or face. MFA combines at least two different factor categories.
