UNIT 1 – MATHEMATICAL LOGIC

Main topics in your notes: conjunction, disjunction, negation, conditional, biconditional, truth tables, tautology, contradiction, contingency, equivalence and normal forms.

1. Proposition / Statement

A proposition is a sentence that is either true or false, but not both.

Example: “2 + 3 = 5” is True. “8 is smaller than 2” is False. A command is not a proposition.

7. Truth table

A truth table shows the output of a logical expression for every possible input combination.

For n variables, number of rows = 2ⁿ. For two variables: 2² = 4 rows. For three variables: 2³ = 8 rows.

Number of rows = 2ⁿ

8. Tautology, contradiction and contingency

Tautology: Always true. Example: P ∨ ¬P = T

Contradiction: Always false. Example: P ∧ ¬P = F

Contingency: Sometimes true and sometimes false.

9. Logical equivalence

Two statements are logically equivalent when their truth-table outputs are the same in every row.

P → Q ≡ ¬P ∨ Q

12. Normal forms – PDNF and PCNF

PDNF: OR of minterms. Select truth-table rows where output is T (1). Each minterm is an AND term containing every variable.

UNIT 2 – RELATIONS

Study the definitions, ordered pairs, properties, composition, matrix and transitive closure. The source scan is difficult to read in places; these are the standard definitions and equations for the named topics.

1. Set and ordered pair

A set is a collection of distinct objects. An ordered pair (a,b) has first element a and second element b; order matters.

(a,b) ≠ (b,a) in general

2. Cartesian product

The Cartesian product A×B is the set of all ordered pairs whose first element comes from A and second comes from B.

A × B = {(a,b) | a∈A, b∈B}
|A × B| = |A| × |B|

Example: A={1,2}, B={x,y}.

A×B={(1,x),(1,y),(2,x),(2,y)}

3. Relation

A relation R from A to B is any subset of A×B.

R ⊆ A × B

Example: A={1,2,3}; R={(1,2),(2,3)}.

4. Domain and range

Domain: all first elements. Range: all second elements appearing in the relation.

For R={(1,a),(2,b),(3,a)}:

Domain={1,2,3}; Range={a,b}

5. Reflexive relation

R is reflexive if every element is related to itself.

∀a∈A, (a,a)∈R

For A={1,2}, a reflexive relation must contain (1,1) and (2,2).

6. Symmetric relation

If a is related to b, then b must be related to a.

(a,b)∈R ⇒ (b,a)∈R

7. Antisymmetric relation

If aRb and bRa are both true, then a and b must be the same element.

aRb ∧ bRa ⇒ a=b

8. Transitive relation

If a is related to b and b is related to c, then a must be related to c.

aRb ∧ bRc ⇒ aRc

Example: (1,2),(2,3) means (1,3) must also exist.

9. Equivalence relation

A relation that is reflexive, symmetric and transitive is an equivalence relation.

Equivalence = Reflexive + Symmetric + Transitive

10. Inverse relation

The inverse relation is obtained by reversing every ordered pair.

R⁻¹={(b,a) | (a,b)∈R}

Example: R={(1,2),(2,3)}; R⁻¹={(2,1),(3,2)}.

11. Composition of relations

Composition joins two relations through a common middle element.

If R={(1,2),(2,3)} and S={(2,a),(3,b)}, then:

S∘R={(1,a),(2,b)}

Rule: aRb and bSc give a(S∘R)c.

12. Matrix representation

A relation matrix uses 1 when a pair exists and 0 when it does not.

For A={1,2}, R={(1,1),(1,2)}:

12
111
200

13. Transitive closure

The transitive closure is the smallest transitive relation containing the original relation.

Given R={(1,2),(2,3)}. Since 1→2 and 2→3, add 1→3.

R⁺={(1,2),(2,3),(1,3)}

14. Digraph

A directed graph represents a relation using vertices (points) and directed edges (arrows).

If (a,b)∈R, draw an arrow from a to b.

UNIT 3 – PARTIAL ORDERING AND LATTICE

Your notes include partial order, total order/chain, upper and lower bounds, supremum/infimum, minimal/maximal elements, Hasse diagrams and lattice properties.

1. Partial order

A relation is a partial order if it is reflexive, antisymmetric and transitive.

Partial order = Reflexive + Antisymmetric + Transitive

2. POSET

A set together with a partial-order relation is called a partially ordered set (POSET).

(P, ≤)

3. Total order / Chain

A partially ordered set is totally ordered (a chain) if every pair of elements is comparable.

For every a,b: a≤b or b≤a

4. Comparable and incomparable

Comparable: a≤b or b≤a. Incomparable: neither a≤b nor b≤a.

Under divisibility, 2 and 3 are incomparable because neither divides the other.

5. Upper bound and lower bound

Upper bound: an element greater than or equal to every element of a subset. Lower bound: an element less than or equal to every element of a subset.

Upper: a≤u for every a∈S
Lower: l≤a for every a∈S

6. LUB / Supremum and GLB / Infimum

LUB (supremum): the least among all upper bounds.

GLB (infimum): the greatest among all lower bounds.

LUB(S)=least upper bound
GLB(S)=greatest lower bound

In divisibility order on divisors of 6, for S={2,3}: LUB=6 and GLB=1.

7. Minimal, maximal, least and greatest

Minimal element: no different element is strictly below it. Maximal element: no different element is strictly above it.

Least element: below every element. Greatest element: above every element.

8. Hasse diagram

A Hasse diagram is a simplified drawing of a finite POSET. It omits self-loops and edges implied by transitivity.

Example: divisors of 6 under divisibility.

9. Lattice

A POSET is a lattice if every pair of elements has both a least upper bound and a greatest lower bound.

Join: a∨b = LUB(a,b)
Meet: a∧b = GLB(a,b)

For divisibility order: Join = LCM; Meet = GCD.

10. Lattice properties / laws

Idempotent: a∨a=a ; a∧a=a
Commutative: a∨b=b∨a ; a∧b=b∧a
Associative: (a∨b)∨c=a∨(b∨c)
Associative: (a∧b)∧c=a∧(b∧c)
Absorption: a∨(a∧b)=a
Absorption: a∧(a∨b)=a

11. Distributive lattice

A lattice is distributive if meet distributes over join and join distributes over meet.

a∧(b∨c)=(a∧b)∨(a∧c)
a∨(b∧c)=(a∨b)∧(a∨c)

11. SOP – Sum of Products

SOP is an OR (sum) of product terms. Each product term is made using AND.

F=AB + A′C

12. POS – Product of Sums

POS is an AND (product) of sum terms. Each sum term is made using OR.

F=(A+B)(A′+C)

13. Karnaugh Map (K-Map)

A K-Map is a diagram method used to simplify Boolean expressions by grouping adjacent cells.

  • SOP: group the 1s.
  • POS: group the 0s.
  • Group sizes: 1, 2, 4, 8, 16 cells.
  • Make the largest possible groups.
  • Edges can wrap around; diagonal cells are not adjacent.

UNIT 5 – FINITE AUTOMATA

Your notes show DFA/NFA comparison, the five-tuple definition, transition function, state diagram/table and string tracing.

1. Finite Automaton

A finite automaton is a machine model with a finite number of states. It reads input symbols and changes states.

2. Five-tuple definition

M=(Q, Σ, δ, q₀, F)
SymbolMeaning
QFinite non-empty set of states
ΣFinite non-empty input alphabet
δTransition / next-state function
q₀Initial state, q₀∈Q
FSet of final states, F⊆Q

3. DFA

DFA means Deterministic Finite Automaton. For each state and input symbol, there is exactly one next state.

δ: Q × Σ → Q

4. NFA

NFA means Nondeterministic Finite Automaton. For a state and input, there may be zero, one or more next states. ε transitions may be allowed in an ε-NFA.

δ: Q × Σ → 2^Q

5. DFA and NFA differences

DFANFA
Exactly one next stateZero or many next states possible
No ε transitionε transition may be allowed
One path for an inputMany possible paths
Accept if its path ends in final stateAccept if at least one path ends in final state

6. Transition function

The transition function tells the next state for a current state and input symbol.

δ(q, a) = next state

Example: δ(q0,a)=q1 means from q0, reading a, go to q1.

7. State table

A state table shows transitions in rows and columns.

Example:

StateInput aInput b
→q0q1q2
*q1q1q0
q2q1q2

→ means initial state; * means final state.

8. State diagram

A state diagram uses circles for states and arrows for transitions.

  • Single arrow entering a state: initial state.
  • Double circle: final state.
  • Arrow label: input symbol.
  • Loop: transition back to same state.

9. Extended transition / reading a string

To process a string, start at q₀ and follow one transition for each symbol from left to right.

Example based on the transition table above: q0 reading “ab”.

q0 --a--> q1 --b--> q0

The string ends in q0. Since q0 is not final, it is rejected.

10. Accepted and rejected strings

Accepted: after reading all symbols, the machine finishes in a final state. Rejected: it does not finish in a final state.

11. Empty string and trap state

Empty string ε: a string containing no symbols.

Trap/dead state: a non-final state from which the machine cannot reach a final state (in a complete DFA, transitions usually loop there).
