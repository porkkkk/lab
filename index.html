UNIT I – An Overview of Java

1. Introduction to Java 8 marks

Definition: Java is a high-level, object-oriented programming language. It was developed by James Gosling at Sun Microsystems and released in 1995.

  1. Simple: Java syntax is easy to learn compared with many older languages.
  2. Object-oriented: Programs are built using classes and objects.
  3. Platform-independent: Java bytecode can run on any computer that has a JVM.
  4. Secure: Java provides features such as bytecode verification and exception handling.
  5. Robust: It supports error handling and automatic memory management.
  6. Multithreaded: It can perform more than one task at a time.
  7. Portable: Java programs can be moved between supported systems.

WORA: Write Once, Run Anywhere. Java source code is compiled into bytecode. The JVM runs that bytecode.

2. OOP principles Very important

Definition: Object-Oriented Programming organizes a program using classes and objects.

  1. Encapsulation: Combines data and methods in one class and protects data. Example: private bank balance.
  2. Inheritance: One class gets properties and methods from another class. It supports code reuse.
  3. Polymorphism: One name can perform different actions. Example: the same method name with different parameters.
  4. Abstraction: Shows important details and hides internal working. Example: using an ATM without knowing its internal process.

Benefits: Code reuse, data protection, easy maintenance and better program organization.

3. Structure of a simple Java program

class Hello {
    public static void main(String[] args) {
        System.out.println("Hello Java");
    }
}
  1. class: Defines a class.
  2. Hello: Class name.
  3. main(): Starting point of the program.
  4. public: JVM can access the method.
  5. static: JVM can call it without creating an object.
  6. void: It does not return a value.
  7. println(): Prints output on the screen.

Execution: Save as Hello.java → compile using javac Hello.java → run using java Hello. Compiler creates bytecode (.class); JVM executes it.

5. Arrays

Definition: An array stores multiple values of the same data type using one variable name. Array size is fixed after creation.

  1. Array elements are stored using index numbers.
  2. Index starts from 0.
  3. All elements have the same data type.
  4. Use length to find the array size.
  5. Arrays can be one-dimensional or multidimensional.
class ArrayDemo {
    public static void main(String[] args) {
        int marks[] = {80, 90, 75};
        for (int i = 0; i < marks.length; i++) {
            System.out.println(marks[i]);
        }
    }
}

Output: 80, 90, 75 (each on a new line).

6. Vector class

Definition: Vector is a growable array in the java.util package. It can increase or decrease its size automatically.

  1. It stores objects, not primitive values directly.
  2. Use wrapper classes such as Integer for numbers.
  3. It allows duplicate values.
  4. It maintains insertion order.
  5. It provides index-based access.
  6. Its methods are synchronized.
import java.util.Vector;
class VectorDemo {
    public static void main(String[] args) {
        Vector v = new Vector();
        v.add("Java");
        v.add("Python");
        System.out.println(v.get(0));
        System.out.println(v.size());
    }
}

Output: Java, then 2.

9. Control statements

Control statements decide the order in which program statements run.

  • Selection: if, if-else, switch. They choose a path.
  • Iteration: for, while, do-while. They repeat statements.
  • Jump: break, continue, return. They change normal flow.
// Largest of three numbers
class Largest {
    public static void main(String[] args) {
        int a = 10, b = 25, c = 15;
        if (a >= b && a >= c)
            System.out.println(a);
        else if (b >= a && b >= c)
            System.out.println(b);
        else
            System.out.println(c);
    }
}

UNIT II – Introducing Classes

11. Class and object

Class: A class is a blueprint or design used to create objects. It contains variables and methods.

Object: An object is an instance of a class. It has state (data) and behaviour (methods).

class Student {
    int mark;
    void show() {
        System.out.println(mark);
    }
}
class Demo {
    public static void main(String[] args) {
        Student s = new Student();
        s.mark = 90;
        s.show();
    }
}

Remember: Class = plan; object = actual item created from the plan.

12. Declaring objects and assigning object references

  1. Declare a reference: Student s;
  2. Create an object: s = new Student();
  3. Both steps together: Student s = new Student();
  4. The new keyword creates an object in memory.
  5. A reference variable stores a reference to the object, not the full object data.
  6. If s2 = s1, both variables refer to the same object.
Student s1 = new Student();
Student s2 = s1; // same object

13. Methods and modular programming

Definition: A method is a block of code that performs one particular task.

  1. Methods divide a large program into small parts.
  2. Each method performs a specific job.
  3. Methods can be called whenever needed.
  4. They reduce repeated code.
  5. They make testing and debugging easier.
  6. A method can return a value or use void when it returns nothing.
class Add {
    int sum(int a, int b) {
        return a + b;
    }
    public static void main(String[] args) {
        Add obj = new Add();
        System.out.println(obj.sum(5, 3));
    }
}

14. Constructors and constructor overloading Very important

Definition: A constructor is a special member used to initialize an object. It runs automatically when an object is created.

  1. Constructor name must be the same as class name.
  2. It has no return type, not even void.
  3. It is called when new creates an object.
  4. A no-argument constructor has no parameters.
  5. A parameterized constructor receives values.
  6. Constructor overloading means having more than one constructor with different parameter lists.
class Student {
    int mark;
    Student() {
        mark = 0;
    }
    Student(int m) {
        mark = m;
    }
    void show() {
        System.out.println(mark);
    }
    public static void main(String[] args) {
        Student a = new Student();
        Student b = new Student(90);
        a.show();
        b.show();
    }
}

Output: 0 and 90. The compiler provides a default constructor only when you do not write any constructor.

15. this keyword

Definition: this refers to the current object.

  1. It refers to the object whose method or constructor is running.
  2. It separates instance variables from parameters with the same name.
  3. this.name means the current object's variable.
  4. It can call another constructor in the same class using this().
class Student {
    int mark;
    Student(int mark) {
        this.mark = mark;
    }
    void show() {
        System.out.println(this.mark);
    }
}

17. Inheritance Very important

Definition: Inheritance allows one class to use the fields and methods of another class. It supports code reuse.

  1. The class whose features are inherited is the parent/superclass.
  2. The class that receives them is the child/subclass.
  3. Java uses the extends keyword for class inheritance.
  4. The child can add its own variables and methods.
  5. It reduces code duplication.
  6. It creates a clear class hierarchy.
class Animal {
    void eat() {
        System.out.println("Eating");
    }
}
class Dog extends Animal {
    void bark() {
        System.out.println("Barking");
    }
}
class Demo {
    public static void main(String[] args) {
        Dog d = new Dog();
        d.eat();
        d.bark();
    }
}

Types: Single, multilevel and hierarchical inheritance. Java supports multiple inheritance of type through interfaces, not by extending multiple classes.

UNIT III – Packages, Interfaces and Exception Handling

18. Package and its advantages Very important

Definition: A package is a group of related classes and interfaces.

  1. It organizes classes into folders/groups.
  2. It avoids class name conflicts.
  3. It controls access to classes and members.
  4. It makes large programs easier to manage.
  5. It supports code reuse.

Creating a package: Write the package statement as the first statement in the Java file.

// File: MyPack/Message.java
package MyPack;
public class Message {
    public void show() {
        System.out.println("Hello from package");
    }
}

Using/importing it:

// File: Test.java
import MyPack.Message;
class Test {
    public static void main(String[] args) {
        Message m = new Message();
        m.show();
    }
}

Compile from the folder above MyPack: javac MyPack/Message.java, then javac Test.java, then java Test.

19. Importing packages

  • import java.util.Scanner; imports one class.
  • import java.util.*; imports accessible classes in that package.
  • java.lang is imported automatically. It contains String, System and Math.
  • Import statements help us use class names without writing the full package name.
  • Use a fully qualified name if two packages contain classes with the same name.

20. Access modifiers and default access

Access modifiers control where a class member can be used.

ModifierSimple meaning
privateOnly inside the same class.
defaultNo keyword; available inside the same package.
protectedSame package and subclasses in other packages (subject to Java access rules).
publicAccessible from anywhere where the class is accessible.

Remember: private = class only; default = package; protected = package + subclass; public = everywhere.

21. Interface and multiple inheritance

Definition: An interface is a set of method declarations and constants that a class agrees to implement. It is used to achieve abstraction and multiple inheritance of type.

  1. Declare an interface using interface.
  2. A class uses implements to use an interface.
  3. The class provides the body for its abstract methods.
  4. A class can implement more than one interface.
  5. Interfaces help different classes follow the same rules.
interface A {
    void showA();
}
interface B {
    void showB();
}
class Demo implements A, B {
    public void showA() {
        System.out.println("A");
    }
    public void showB() {
        System.out.println("B");
    }
    public static void main(String[] args) {
        Demo d = new Demo();
        d.showA();
        d.showB();
    }
}

22. Exception handling Very important

Definition: Exception handling is a way to handle runtime errors so that the program can continue or end safely.

  1. try: Contains code that may cause an exception.
  2. catch: Handles the exception.
  3. finally: Runs whether an exception occurs or not; often used to close resources.
  4. throw: Manually throws an exception.
  5. throws: Declares that a method may pass an exception to its caller.
  6. It prevents sudden program termination and helps show meaningful error messages.
class Demo {
    public static void main(String[] args) {
        try {
            int a = 10 / 0;
        }
        catch (ArithmeticException e) {
            System.out.println("Cannot divide by zero");
        }
        finally {
            System.out.println("Program finished");
        }
    }
}

23. Multiple catch blocks

One try block may produce different exceptions. Multiple catch blocks handle different types.

  1. Write one try block.
  2. Write a separate catch block for each exception type.
  3. Java checks catch blocks from top to bottom.
  4. The first matching catch block runs.
  5. Put a more specific exception before a general Exception catch.
try {
    int a = 10 / 0;
    int x[] = {1, 2};
    System.out.println(x[5]);
}
catch (ArithmeticException e) {
    System.out.println("Divide by zero");
}
catch (ArrayIndexOutOfBoundsException e) {
    System.out.println("Wrong array index");
}

UNIT IV – Multithreading and Input/Output

25. Multithreading and its advantages Very important

Definition: Multithreading means running two or more threads (small paths of execution) in one program.

  1. A thread is a lightweight unit of execution.
  2. Threads share the same process memory.
  3. One thread can work while another waits for file or network input.
  4. It improves responsiveness.
  5. It helps use CPU time efficiently.
  6. It is useful in games, servers and interactive programs.

Two ways to create: extend the Thread class or implement the Runnable interface.

26. Creating a thread using Runnable Asked in paper

  1. Create a class that implements Runnable.
  2. Write the task inside run().
  3. Create a Runnable object.
  4. Pass it to a Thread object.
  5. Call start() to begin a new thread. Do not call run() directly to start a new thread.
class MyTask implements Runnable {
    public void run() {
        System.out.println("Thread is running");
    }
}
class Demo {
    public static void main(String[] args) {
        MyTask task = new MyTask();
        Thread t = new Thread(task);
        t.start();
    }
}

27. Thread life cycle and thread methods

Basic exam explanation: A thread is created, becomes ready to run, gets CPU time, may wait or sleep, and finally finishes. Modern Java describes states as NEW, RUNNABLE, BLOCKED, WAITING, TIMED_WAITING and TERMINATED.

MethodUse
start()Starts a new thread.
run()Contains the task.
sleep(ms)Pauses current thread for a time.
join()Waits for another thread to finish.
isAlive()Checks whether thread is alive.
getName()/setName()Gets/sets thread name.
yield()Gives other threads a chance to run.
interrupt()Interrupts a waiting or sleeping thread.

28. Synchronization

Definition: Synchronization controls access to shared data so that only one thread at a time enters a synchronized method or block for the same lock.

  1. Multiple threads may use the same data.
  2. At the same time, they may interfere with each other.
  3. This can cause a race condition and incorrect output.
  4. The synchronized keyword uses an object's lock.
  5. Other threads wait until the lock is released.
class Counter {
    int count = 0;
    synchronized void add() {
        count++;
    }
}

29. Java file handling

Definition: File handling means creating, reading, writing and managing data stored in files.

  1. Java file and I/O classes are mainly available in java.io.
  2. File represents a file or directory path.
  3. FileReader reads text characters.
  4. FileWriter writes text characters.
  5. FileInputStream reads bytes.
  6. FileOutputStream writes bytes.
  7. Close files after use, or use try-with-resources.
import java.io.FileReader;
class ReadFile {
    public static void main(String[] args) throws Exception {
        FileReader r = new FileReader("data.txt");
        int ch;
        while ((ch = r.read()) != -1) {
            System.out.print((char) ch);
        }
        r.close();
    }
}

31. String, StringBuffer and StringBuilder

String: A String stores text. It is immutable, which means its value cannot be changed after creation. A change creates a new String.

StringBuffer: A changeable (mutable) sequence of characters. Its methods are synchronized.

StringBuilder: Also mutable, but its methods are not synchronized. It is usually faster when synchronization is not needed.

StringStringBufferStringBuilder
ImmutableMutableMutable
New object for changed valueChanges same objectChanges same object
Safe immutable textSynchronized methodsNot synchronized
class StringDemo {

        StringBuffer s = new StringBuffer("Hello");
        s.append(" Java");
        System.out.println(s);
        StringBuilder b = new StringBuilder("Good");
        b.append(" Morning");
        System.out.println(b);
    }
}

UNIT V – AWT and Swing

32. AWT and its features

Definition: AWT means Abstract Window Toolkit. It is Java's original GUI toolkit used to create windows, buttons, labels and other interface elements.

  1. AWT classes are mainly in the java.awt package.
  2. It creates graphical user interfaces.
  3. It provides controls such as Button, Label, TextField, Checkbox and List.
  4. It provides containers such as Frame and Panel.
  5. It supports layout managers.
  6. It supports event handling for user actions.
  7. AWT components are heavyweight and use native operating-system peers.

34. Event delegation model in AWT

Definition: The event delegation model handles user actions by sending an event from a component to a registered listener.

  1. Event source: The component where the action happens, such as a Button.
  2. Event object: Contains information about the event.
  3. Event listener: An object that waits for and handles the event.
  4. Register the listener using a method such as addActionListener().
  5. When the user clicks the button, Java calls the listener method.
import java.awt.*;
import java.awt.event.*;
class ButtonDemo extends Frame implements ActionListener {
    Button b;
    ButtonDemo() {
        b = new Button("Click");
        add(b);
        b.addActionListener(this);
        setSize(250, 150);
        setLayout(new FlowLayout());
        setVisible(true);
    }
    public void actionPerformed(ActionEvent e) {
        System.out.println("Button clicked");
    }
    public static void main(String[] args) {
        new ButtonDemo();
    }
}

35. Swing and its features

Definition: Swing is a Java GUI library that provides flexible components for building desktop applications.

  1. Swing components are mainly in javax.swing.
  2. It provides components such as JButton, JLabel and JTextField.
  3. Most Swing components are lightweight.
  4. It supports pluggable look and feel.
  5. It provides more components than basic AWT.
  6. It supports icons, borders, tooltips and advanced controls.
  7. Swing is built on top of AWT.

37. MVC architecture in Swing Asked in paper

MVC means Model–View–Controller. It separates a user interface into three parts.

  1. Model: Stores data or state. Example: whether a checkbox is selected.
  2. View: Displays the component on the screen.
  3. Controller: Handles user actions such as clicks and typing and updates the model.
  4. The view displays the updated model.
  5. Separating these parts makes programs easier to change, test and maintain.

Flow: User action → Controller → Model changes → View displays updated state.

40. Simple Swing login form program

import javax.swing.*;
import java.awt.*;
import java.awt.event.*;

class Login {
    public static void main(String[] args) {
        JFrame f = new JFrame("Login Form");
        JLabel user = new JLabel("Username:");
        JTextField name = new JTextField(15);
        JLabel pass = new JLabel("Password:");
        JPasswordField password = new JPasswordField(15);
        JButton login = new JButton("Login");

        f.setLayout(new FlowLayout());
        f.add(user);
        f.add(name);
        f.add(pass);
        f.add(password);
        f.add(login);

        login.addActionListener(new ActionListener() {
            public void actionPerformed(ActionEvent e) {
                JOptionPane.showMessageDialog(f,
                    "Welcome " + name.getText());
            }
        });

        f.setSize(300, 180);
        f.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        f.setVisible(true);
    }
}

Explanation: JFrame creates the window. JLabel displays field names. JTextField accepts username. JPasswordField accepts password. JButton creates the Login button. ActionListener handles the click.
