UNIT I – An Overview of Java

Basics • OOP • Data • Loops

1. Introduction to Java

Meaning: Java is a high-level, object-oriented programming language. It is used to create desktop, web and many other applications.

  • Java was developed by James Gosling and his team at Sun Microsystems.
  • It was first called Oak and later renamed Java.
  • Java 1.0 was released in 1995.
  • Java source code is saved with the .java extension.
  • The Java compiler converts source code into bytecode.
  • The JVM runs the bytecode on a computer.

WORA: Write Once, Run Anywhere. The same bytecode can run on different systems that have a suitable JVM.

2. Features of Java

  1. Simple: Java has clear syntax and removes many complex features.
  2. Object-oriented: Programs use classes and objects.
  3. Platform-independent: Bytecode can run on different operating systems using JVM.
  4. Secure: Java checks bytecode and provides security features.
  5. Robust: Exception handling helps manage errors.
  6. Multithreaded: More than one task can make progress at the same time.
  7. Portable: Java programs can be moved between supported systems.
  8. Automatic memory management: Garbage collection helps remove unused objects.

3. Structure of a simple Java program

  1. Class: Java code is written inside a class.
  2. main method: It is the starting point of a normal Java application.
  3. Statements: Instructions that perform work.
  4. Braces: Curly braces show the beginning and end of a block.
  5. Semicolon: Most Java statements end with a semicolon.
class Hello { public static void main(String[] a) {
 System.out.println("Hello Java"); } }

Execution: Write file → compile using javac Hello.java → run using java Hello → output appears.

4. Blocks of code

  • A block is a group of statements inside { }.
  • A class body is a block.
  • A method body is a block.
  • if, loops and other control statements can also contain blocks.
  • Blocks help group related statements together.
if (age >= 18) { System.out.println("Adult"); }

A data type tells Java what kind of value can be stored in a variable.

Two groups: Primitive types store simple values. Reference types refer to objects, such as String, arrays and class objects.

6. Variables

  • A variable is a named place used to store a value.
  • Declaration tells Java the variable's name and type.
  • Initialisation gives the variable its first value.
  • Local variables are declared inside methods or blocks.
  • Instance variables belong to objects.
  • Static variables belong to the class.
int mark; mark = 90; // declaration and value

7. Type conversion and casting

  • Type conversion changes a value from one data type to another.
  • Widening conversion is usually automatic, such as int to double.
  • Narrowing conversion needs a cast, such as double to int.
  • Narrowing can lose some information.
double x = 10; int y = (int) 4.8;

8. Arrays

  • An array stores many values of the same data type.
  • Array size is fixed after creation.
  • Index starts at 0.
  • Use length to get array size.
  • Array values are accessed using index numbers.
  • Arrays can be one-dimensional or multidimensional.
int[] marks = {80,90,70}; System.out.println(marks[0]);

Output: 80. The first item is at index 0.

9. Vector

  • Vector is a growable array class in java.util.
  • Its size can increase when new items are added.
  • It stores objects; wrapper classes are used for primitive values.
  • It allows duplicate values.
  • It keeps the insertion order.
  • Its methods are synchronized.
  • Common methods: add(), get(), remove(), size(), clear().
Vector<String> v = new Vector<>(); v.add("Java");

12. Control statements

Control statements decide which statement runs and how many times it runs.

Selection statements:

  • if: runs code when a condition is true.
  • if-else: chooses between two paths.
  • else-if ladder: checks many conditions in order.
  • switch: selects a case based on a value.
if (mark >= 40) System.out.println("Pass"); else System.out.println("Fail");

Iteration statements:

  • while: checks condition before the body.
  • do-while: runs body once before checking condition.
  • for: puts start, condition and update in one statement.
  • for-each: visits each item in an array or collection.
for (int i=1; i<=5; i++) System.out.println(i);

Jump statements: break exits a loop or switch; continue skips to the next loop round; return exits a method.

UNIT II – Introducing Classes

Class • Object • Constructor

1. Class fundamentals

  • A class is a blueprint or design for creating objects.
  • It contains variables and methods.
  • Variables describe the data or state.
  • Methods describe the actions or behaviour.
  • Objects are created from a class.
  • A class helps organise related data and actions.
class Student { int mark; void show(){ System.out.println(mark); } }

2. Object

  • An object is an instance of a class.
  • It has state, behaviour and identity.
  • State means the values stored in its variables.
  • Behaviour means the work done by its methods.
  • Objects are normally created using the new keyword.
  • Members are accessed using the dot operator.
Student s = new Student(); s.mark = 90;

3. Declaring objects and reference variables

  • A reference variable stores a reference to an object, not the complete object data itself.
  • First, declare a reference variable using the class name.
  • Use new to create an object.
  • Assign the created object's reference to the variable.
  • Two reference variables can point to the same object.
  • null means the reference does not currently refer to an object.
Student a = new Student(); Student b = a;

Here, a and b refer to the same Student object.

4. Methods

  • A method is a named block of code that performs a task.
  • A method can receive values called parameters.
  • A method can return a result.
  • void means it does not return a value.
  • Methods divide a large program into small parts.
  • They reduce repeated code and make testing easier.
int add(int a,int b){ return a+b; } // returns the sum

5. Constructors

  • A constructor is used to initialise an object.
  • Its name must be the same as the class name.
  • It has no return type, not even void.
  • It is called automatically when an object is created with new.
  • A constructor can receive parameters.
  • If no constructor is written, Java supplies a default constructor.

Types: no-argument constructor and parameterized constructor. A programmer-written no-argument constructor is not the same as the compiler-provided default constructor.

Student(){ mark=0; } Student(int m){ mark=m; }

6. Constructor overloading

  • Constructor overloading means creating more than one constructor in the same class.
  • Each constructor must have a different parameter list.
  • They can have different numbers or types of parameters.
  • It gives different ways to initialise objects.
  • The correct constructor is selected based on the arguments.
Box(){size=1;} Box(int n){size=n;}

7. this keyword

  • this refers to the current object.
  • It is used when a parameter and instance variable have the same name.
  • It can call another constructor in the same class using this().
  • It can pass the current object as an argument.
  • It makes it clear which variable belongs to the current object.
Student(int mark){ this.mark = mark; }

8. Method overloading

  • Same method name is used more than once in a class.
  • Parameter lists must be different.
  • Parameters can differ in number, type or order.
  • It improves readability because similar tasks use one name.
  • It is an example of compile-time polymorphism.
  • Changing only the return type is not enough for overloading.
int add(int a,int b){return a+b;} double add(double a,double b){return a+b;}

9. Method overriding

  • Overriding happens when a child class provides its own version of an inherited method.
  • The method name and parameter list match the parent method.
  • It requires inheritance.
  • The child method gives a different behaviour.
  • It supports runtime polymorphism.
class Dog extends Animal { void sound(){ System.out.println("Bark"); } }

10. Inheritance

  • Inheritance allows one class to use accessible members of another class.
  • The existing class is called parent or superclass.
  • The new class is called child or subclass.
  • Java uses the extends keyword for class inheritance.
  • It supports code reuse and avoids repeated code.
  • The super keyword refers to parent-class members and constructors.

Types: single, multilevel and hierarchical class inheritance. Java does not support multiple inheritance through classes; interfaces can be implemented together.

class Animal { void eat(){} } class Dog extends Animal { void bark(){} }

11. Access control in classes

ModifierSimple meaning
privateAccessible only inside the same class
defaultAccessible within the same package
protectedSame package and subclasses under Java's protected access rules
publicAccessible from other classes where the class itself is visible

Access modifiers help protect data and control which parts of a program can use class members.

UNIT III – Packages and Interfaces

Package • Interface • Exception

1. Package

  • A package is a group of related classes and interfaces.
  • It organises Java programs.
  • It prevents naming conflicts between classes.
  • It provides access control.
  • It makes large programs easier to manage.
  • Java has built-in packages such as java.lang, java.util, java.io and java.awt.
package college; // place at the top of the source file

2. Creating and using a user-defined package

  1. Create a folder for the package.
  2. Write the package statement at the top of the Java source file.
  3. Write a class inside the package.
  4. Compile the class with the correct folder structure.
  5. In another program, import the required class.
  6. Create its object and call its accessible methods.
package college; public class Student { public void show(){} }

Import example: import college.Student;. To import all public types in a package, use import college.*;.

3. Packages and member access

  • private members are available only inside their own class.
  • default members are available within the same package.
  • protected members are available in the same package and in subclasses, subject to protected-access rules.
  • public members can be accessed wherever the declaring type is visible.
  • These rules control how classes share their members.

4. Interface

  • An interface is a contract that tells a class which behaviours it must provide.
  • It is declared using the interface keyword.
  • A class uses implements to use an interface.
  • The class must implement its abstract methods unless the class is abstract.
  • Interface fields are public, static and final by default.
  • Traditional abstract interface methods are public and abstract by default.
  • Modern Java also supports default, static and private interface methods.
interface Print { void show(); } class A implements Print { public void show(){} }

5. Multiple inheritance using interfaces

  • Multiple inheritance means receiving features from more than one parent type.
  • Java does not allow a class to extend two classes.
  • A class can implement more than one interface.
  • Each interface gives a contract of methods.
  • The class provides the required method bodies.
  • This supports flexible design without multiple class inheritance.
class Phone implements Camera, MusicPlayer { /* methods */ }

6. Default, static and private interface methods

  • Default method: has a method body and is available to implementing classes.
  • Static method: belongs to the interface and is called using the interface name.
  • Private method: helper method used inside the interface to share code between its methods.
  • These features allow interfaces to provide some reusable behaviour.
interface A { default void show(){ } static void help(){ } }

7. Exception handling

  • An exception is an unwanted event during program execution.
  • It can interrupt the normal flow of a program.
  • Exception handling allows the program to respond to an error.
  • try contains code that may cause an exception.
  • catch handles the exception.
  • finally is used for cleanup and normally runs whether an exception occurs or not.
  • throw throws an exception object.
  • throws declares possible exceptions in a method header.
try { int x=10/0; } catch(ArithmeticException e) { System.out.println("Error"); }

8. Types of exceptions

  • Checked exceptions: compiler requires the program to catch them or declare them. Example: IOException.
  • Unchecked exceptions: occur at runtime and are not required to be declared. Example: ArithmeticException.
  • Error: serious problem generally not handled by normal application code. Example: OutOfMemoryError.

9. Multiple catch blocks

  • One try block can have more than one catch block.
  • Each catch block handles a different exception type.
  • Java checks catch blocks from top to bottom.
  • The first matching catch block runs.
  • Specific exception catches must come before a general Exception catch.
  • This lets a program show a suitable message for each error.
try { int x=10/0; } catch(ArithmeticException e) { System.out.println("Divide by zero"); }

10. throw and throws – difference

throwthrows
Used inside a method or blockUsed in method declaration
Actually throws an exception objectDeclares possible exceptions
Followed by an exception objectFollowed by exception class names
Example: throw new IOException();Example: void read() throws IOException

UNIT IV – Multithreading and I/O

Thread • File • Stream • String

1. Thread

  • A thread is a small path of execution inside a program.
  • A Java program can have more than one thread.
  • Each thread performs a task.
  • Threads in the same process share resources such as memory.
  • They can make a program more responsive.

Example: a music player can play music while another thread downloads a file.

2. Multithreading

  • Multithreading means using multiple threads in one program.
  • Different tasks can make progress concurrently.
  • It improves responsiveness.
  • It can make better use of processor time.
  • It is useful in games, servers and user-interface programs.
  • Shared data must be managed carefully to avoid errors.

3. Creating a thread using Thread class

  1. Create a class that extends Thread.
  2. Override the run() method.
  3. Create an object of the class.
  4. Call start() to begin a new thread.
  5. The JVM schedules the thread and calls run().
class Work extends Thread { public void run(){ System.out.println("Work"); } }

4. Creating a thread using Runnable interface

  1. Create a class that implements Runnable.
  2. Write the task inside the run() method.
  3. Create an object of that class.
  4. Pass the object to a Thread object.
  5. Call start() to start the new thread.
  6. Runnable is useful when the class must extend another class too.
class Work implements Runnable { public void run(){ System.out.println("Work"); } }

Start statement: new Thread(new Work()).start();

5. Thread life cycle

  1. NEW: thread object is created but not started.
  2. RUNNABLE: thread is ready or running.
  3. BLOCKED: thread waits to get a lock.
  4. WAITING: thread waits until another action happens.
  5. TIMED_WAITING: thread waits for a set time.
  6. TERMINATED: thread has finished its work.

Flow: NEW → RUNNABLE → waiting/blocked state → RUNNABLE → TERMINATED.

7. Synchronization

  • Synchronization controls access to shared data.
  • It is used when many threads use the same object or data.
  • A synchronized method or block uses an object's lock.
  • Only one thread at a time can hold that same object's lock for the protected code.
  • It helps prevent race conditions and incorrect shared data.
synchronized void add(){ count++; }

8. File handling and File class

  • File handling means reading data from files and writing data to files.
  • Java I/O classes are mainly in the java.io package.
  • The File class represents a file or directory.
  • File class can check name, path, size and existence.
  • File itself does not read or write the file's contents.
  • Useful methods: exists(), getName(), getPath(), length(), delete(), mkdir().

9. Stream classes

  • A stream is a flow of data between a program and an input/output source.
  • Input stream brings data into the program.
  • Output stream sends data out of the program.
  • Byte streams handle raw bytes.
  • Character streams handle text characters.
  • Buffered streams improve performance by using a buffer.

10. Byte streams and character streams

11. Reading a file using FileReader

  • FileReader is a character stream class.
  • It reads text from a file.
  • It can read one character at a time.
  • read() returns -1 when the end of the file is reached.
  • Close the reader after use, or use try-with-resources.
try (FileReader r=new FileReader("a.txt")) { int c; while((c=r.read())!=-1) System.out.print((char)c); }

12. FileWriter

  • FileWriter writes characters into a text file.
  • It belongs to the character stream family.
  • It can create a new file if it does not exist.
  • It can write text using write().
  • Close the writer after writing to finish the output.
try (FileWriter w=new FileWriter("a.txt")) { w.write("Hello"); }

13. String

  • A String is a sequence of characters.
  • String is a class in java.lang.
  • String objects are immutable.
  • Immutable means the object cannot be changed after creation.
  • When a String is changed, a new String object is created.
  • Common methods include length(), charAt(), substring(), equals(), and toUpperCase().
String name="Java"; System.out.println(name.length());

14. StringBuffer

  • StringBuffer stores a changeable sequence of characters.
  • It is mutable.
  • Its methods are synchronized.
  • It is suitable when multiple threads may modify the same text object.
  • Common methods: append(), insert(), delete(), replace(), reverse(), length().
StringBuffer s=new StringBuffer("Java"); s.append(" Exam");

15. StringBuilder

  • StringBuilder stores a changeable sequence of characters.
  • It is mutable.
  • Its methods are not synchronized.
  • It is usually faster than StringBuffer in single-threaded use.
  • Common methods: append(), insert(), delete(), replace(), reverse().
StringBuilder s=new StringBuilder("Java"); s.append(" Exam");

UNIT V – AWT and Swing

GUI • Event • MVC

1. AWT

  • AWT means Abstract Window Toolkit.
  • It is Java's original graphical user interface toolkit.
  • It is mainly available in the java.awt package.
  • It helps create windows, buttons, labels, text fields and menus.
  • It provides drawing, colour, font and layout features.
  • AWT components generally use native operating-system peers and are heavyweight.

2. AWT components

3. Layout managers

  • FlowLayout: places components one after another, from left to right.
  • BorderLayout: uses North, South, East, West and Center areas.
  • GridLayout: arranges components in rows and columns of equal cells.
  • CardLayout: displays one card or component at a time.
  • GridBagLayout: provides flexible grid placement.

4. Event and event handling

  • An event is an action performed by the user or system.
  • Examples include button click, key press and mouse click.
  • Event handling means responding to that action.
  • A listener waits for an event and runs code when it happens.
  • Listeners are registered with components.

5. Event delegation model

  1. Event source: the component that creates the event, such as a button.
  2. Event object: contains information about the event, such as ActionEvent.
  3. Event listener: receives and handles the event, such as ActionListener.
  4. The listener is registered with the source.
  5. When the user clicks, the source sends the event to the listener.
  6. The listener runs its event-handling method.
button.addActionListener(e -> System.out.println("Clicked"));

6. Swing

  • Swing is a Java GUI toolkit built on AWT.
  • It provides more GUI components than AWT.
  • Most Swing components are lightweight.
  • It supports pluggable look and feel.
  • It is used to create desktop windows, forms, buttons and lists.
  • Main package is javax.swing.

7. Swing components

8. Swing packages

  • javax.swing – main Swing components.
  • javax.swing.event – Swing event classes and listeners.
  • javax.swing.border – component borders.
  • javax.swing.filechooser – file chooser support.
  • javax.swing.table – table components.
  • javax.swing.tree – tree components.
  • javax.swing.text – text component support.
  • javax.swing.plaf – pluggable look and feel support.

9. MVC architecture in Swing

MVC means Model–View–Controller. It divides a user interface into three parts.

  1. Model: stores the data or state. Example: whether a checkbox is selected.
  2. View: shows the component on the screen.
  3. Controller: handles user actions such as clicking or typing and updates the model.

Working: user performs an action → controller responds → model changes → view shows the updated information.

Advantages: easy to understand, easier maintenance, separation of work and easier changes.

Important 5-mark questions and answers

Point-wise answers
1. Explain the features of Java.
  1. Java is simple and easy to learn.
  2. It is object-oriented and uses classes and objects.
  3. It is platform-independent because JVM runs bytecode.
  4. It is secure and robust.
  5. It supports multithreading.
  6. It is portable and has automatic memory management.

Example: One compiled Java program can run on different systems with a JVM.

2. Explain primitive data types in Java.
  1. Java has eight primitive data types.
  2. byte, short, int and long store whole numbers.
  3. float and double store decimal numbers.
  4. char stores one character.
  5. boolean stores true or false.

Example: int age=20; char grade='A'; boolean pass=true;

3. Explain arrays and Vector.
  1. Array stores many values of the same type.
  2. Array size is fixed.
  3. Array index starts from zero.
  4. Vector is a growable array in java.util.
  5. Vector can grow when new values are added.
  6. Vector methods are synchronized.

Example: int[] a={10,20}; and Vector<String> v=new Vector<>();

4. Differentiate while, do-while and for loops.
  1. while checks condition before executing the body.
  2. do-while checks condition after the body.
  3. do-while runs at least once.
  4. for loop has initialisation, condition and update in one line.
  5. for is useful when the number of repetitions is known.

Example: for(int i=1;i<=5;i++) System.out.println(i);

5. Explain constructors.
  1. Constructor initialises an object.
  2. Its name is the same as the class.
  3. It has no return type.
  4. It runs when an object is created.
  5. It can have no parameters or parameters.
  6. More than one constructor can be overloaded.

Example: Box(){size=1;} Box(int n){size=n;}

6. Explain this keyword.
  1. this refers to the current object.
  2. It can access current object's variables.
  3. It distinguishes instance variables from parameters.
  4. It can call another constructor using this().
  5. It can pass the current object to a method.

Example: Student(int mark){this.mark=mark;}

7. Explain method overloading and overriding.
  1. Overloading uses the same method name with different parameters.
  2. Overloading is generally compile-time polymorphism.
  3. Overriding gives a child class its own version of an inherited method.
  4. Overriding requires inheritance.
  5. Overriding supports runtime polymorphism.

Example overloading: add(int a,int b) and add(double a,double b).

8. Explain packages and their advantages.
  1. Package is a group of related classes and interfaces.
  2. It organises code.
  3. It avoids class-name conflicts.
  4. It provides access control.
  5. It makes large programs easier to manage.

Example: package college; and import college.Student;.

9. Explain interfaces.
  1. Interface defines a contract for classes.
  2. It is declared using interface.
  3. A class uses implements.
  4. The class provides method bodies.
  5. A class can implement more than one interface.

Example: class Phone implements Camera, Music { }

10. Explain exception handling keywords.
  1. try contains risky code.
  2. catch handles an exception.
  3. finally is used for cleanup.
  4. throw manually throws an exception.
  5. throws declares possible exceptions in a method header.

Example: try { int x=10/0; } catch(Exception e) { }

11. Explain thread life cycle.
  1. NEW: thread object is created.
  2. RUNNABLE: thread is ready or running.
  3. BLOCKED: waiting for a lock.
  4. WAITING: waiting for another action.
  5. TIMED_WAITING: waiting for a fixed time.
  6. TERMINATED: thread has finished.

Flow: NEW → RUNNABLE → waiting states → RUNNABLE → TERMINATED.

12. Explain byte and character streams.
  1. Byte streams handle raw bytes.
  2. They are useful for images and binary files.
  3. InputStream and OutputStream are base classes.
  4. Character streams handle text characters.
  5. Reader and Writer are base classes.
  6. FileReader and FileWriter are character stream classes.
13. Explain String, StringBuffer and StringBuilder.
  1. String stores a sequence of characters and is immutable.
  2. StringBuffer is mutable and synchronized.
  3. StringBuilder is mutable and not synchronized.
  4. StringBuffer is useful for thread-safe changes.

1. Explain the principles of Object-Oriented Programming with examples.

Introduction

Object-Oriented Programming (OOP) is a way of writing programs using classes and objects. It helps organise a program into smaller parts.

Main principles

  1. Encapsulation: It combines data and methods inside one class. It protects data using access modifiers such as private. Example: a bank account keeps its balance private.
  2. Inheritance: A child class receives accessible features from a parent class. It saves time and avoids repeated code. Example: Dog can inherit from Animal.
  3. Polymorphism: One method name can perform different actions. Example: sound() can make a dog bark and a cat meow.
  4. Abstraction: It shows only necessary details and hides internal working. Example: a person drives a car without knowing the full engine process.

Advantages

  1. Code can be reused.
  2. Data can be protected.
  3. Programs are easier to maintain.
  4. Large programs can be divided into classes.
  5. It improves flexibility.
class Animal { void sound(){} } class Dog extends Animal { }

Conclusion

OOP makes programs organised, reusable and easier to maintain.

2. Explain the structure of a simple Java program and its execution process.

Meaning

A Java program is written inside a class. The main() method is the starting point of a normal Java application.

Structure

  1. Class declaration: gives a name to the class.
  2. main method: contains the starting instructions.
  3. Statements: perform actions such as displaying output.
  4. Braces: mark the beginning and end of a block.
  5. Semicolon: ends most statements.
class Hello { public static void main(String[] a) { System.out.println("Hello"); } }

Execution process

  1. Write the program and save it as Hello.java.
  2. Use javac Hello.java to compile it.
  3. The compiler creates bytecode in Hello.class.
  4. The JVM loads and checks the bytecode.
  5. The JVM runs the program.
  6. The output is displayed on the screen.

Conclusion

Java uses compilation and JVM execution to run programs on supported systems.

8. Explain exception handling with multiple catch blocks.

Meaning

An exception is an unwanted event that interrupts the normal flow of a program. Exception handling helps the program respond to the problem.

Keywords

  4. throw: manually throws an exception object.

10. Explain thread life cycle with its states.

Meaning

A thread passes through different states from creation until it finishes.

  1. NEW: thread object is created, but start() has not been called.
  2. RUNNABLE: thread is ready to run or is running.
  3. BLOCKED: thread is waiting to get a monitor lock.
  4. WAITING: thread waits for another thread or action without a time limit.
  5. TIMED_WAITING: thread waits for a fixed time, such as during sleep().
  6. TERMINATED: thread has completed its run() method.

Flow

NEW → RUNNABLE → BLOCKED / WAITING / TIMED_WAITING → RUNNABLE → TERMINATED.

Important methods

  • start() starts the thread.
  • sleep() pauses the current thread.
  • join() waits for another thread to finish.
  • isAlive() checks whether the thread is alive.

Conclusion

The life cycle explains how a thread moves from creation to completion.

The event delegation model is the way Java sends an event from a component to a listener that handles it.

Main parts

  3. Event listener: receives and handles the event, such as ActionListener.
  4. The listener is registered using a method such as addActionListener().
  5. When the user clicks the button, the source sends the event to the listener.
