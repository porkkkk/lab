UNIT 01

An Overview of Java

Fundamentals · OOP · Control flow
Q1

Explain the principles of Object-Oriented Programming with examples.

8+ MARKS
Definition: Object-Oriented Programming (OOP) is a programming method in which a program is designed using classes and objects. Objects contain data and methods that work with the data.

In OOP, objects interact with one another to complete a task. Java is an object-oriented programming language. The main principles help programmers create organised, reusable and secure programs.

1. Encapsulation

  • Encapsulation means combining data and methods inside one class.
  • It protects data from unwanted outside access.
  • Data can be declared private and accessed through public methods.
  • Example: A bank account keeps its balance private. The user changes it through deposit and withdraw methods.

2. Inheritance

  • Inheritance allows one class to use accessible properties and methods of another class.
  • The existing class is called the parent or superclass.
  • The new class is called the child or subclass.
  • Java uses the extends keyword for class inheritance.
  • Example: Dog can inherit the eat() method from Animal.

3. Polymorphism

  • Polymorphism means one name can have many forms.
  • The same method name can perform different tasks.
  • Method overloading is compile-time polymorphism.
  • Method overriding is runtime polymorphism.
  • Example: A sound() method can print different sounds for Dog and Cat.

4. Abstraction

  • Abstraction means showing important features and hiding internal working details.
  • It makes a program easier to use.
  • Java supports abstraction through abstract classes and interfaces.
  • Example: A driver uses a steering wheel without knowing the complete working of the engine.

Small Java example

class Animal {
    void sound() {
        System.out.println("Animal makes a sound");
    }
}
class Dog extends Animal {
    void bark() {
        System.out.println("Dog barks");
    }
}
class Demo {
    public static void main(String[] args) {
        Dog d = new Dog();
        d.sound();
        d.bark();
    }
}

Advantages of OOP

  1. Code can be reused through inheritance.
  2. Data can be protected through encapsulation.
  3. Programs become easier to maintain.
  4. Abstraction reduces complexity.
  5. Polymorphism provides flexibility.
Remember: Four principles = Encapsulation, Inheritance, Polymorphism and Abstraction (EIPA).

Conclusion: OOP makes Java programs reusable, secure, flexible and easy to maintain.

Q2

Write a Java program to find the largest of three numbers using if-else.

8+ MARKS
Definition: The if-else statement is a decision-making statement. It checks a condition and executes the matching block.

Algorithm

  1. Start the program.
  2. Declare three integer variables a, b and c.
  3. Check whether a is greater than or equal to b and c.
  4. If true, print a as the largest.
  5. Otherwise check whether b is greater than or equal to a and c.
  6. If true, print b; otherwise print c.
  7. Stop the program.

Java program

class Largest {
    public static void main(String[] args) {
        int a = 10;
        int b = 25;
        int c = 15;

        if (a >= b && a >= c) {
            System.out.println("Largest = " + a);
        }
        else if (b >= a && b >= c) {
            System.out.println("Largest = " + b);
        }
        else {
            System.out.println("Largest = " + c);
        }
    }
}

Output

Largest = 25

Explanation

  1. Three numbers are stored in a, b and c.
  2. The first if checks whether a is the largest.
  3. The && operator means both conditions must be true.
  4. If the first condition is false, the else-if checks b.
  5. If both conditions are false, c is the largest.
  6. The System.out.println() statement displays the result.

Conclusion: The if-else ladder compares all three values and prints the largest number.

Q3

Differentiate between while, do-while and for loops with examples.

8+ MARKS
Definition: A loop is a control statement that repeats a block of code while a condition is satisfied.

1. while loop

  • It is an entry-controlled loop.
  • The condition is checked before the loop body executes.
  • If the condition is false at the beginning, the body does not execute.
  • It is useful when the number of repetitions is not known.
int i = 1;
while (i <= 3) {
    System.out.println(i);
    i++;
}

2. do-while loop

  • It is an exit-controlled loop.
  • The body executes before the condition is checked.
  • It executes at least one time.
  • It is useful when the task must happen once before checking the condition.
int i = 1;
do {
    System.out.println(i);
    i++;
} while (i <= 3);

3. for loop

  • It is an entry-controlled loop.
  • Initialisation, condition and update are written in one line.
  • It is useful when the number of repetitions is known.
  • It makes counting loops easy to read.
for (int i = 1; i <= 3; i++) {
    System.out.println(i);
}

Conclusion: The three loops repeat statements, but they differ in when they test the condition and how their control parts are written.

Introduction to Java

Java is a high-level, class-based, object-oriented programming language. Java source code is compiled into bytecode, which is executed by the Java Virtual Machine (JVM).
  • Simple: Its syntax is easier to learn than many low-level languages.
  • Object-oriented: Uses classes and objects.
  • Platform-independent: Bytecode runs on systems with a compatible JVM.
  • Secure: Includes runtime checks and security features.
  • Robust: Provides exception handling and automatic memory management.
  • Multithreaded: Supports multiple threads in one program.
  • Portable: Programs can be moved between supported systems.

Q1

Describe constructors in Java and explain constructor overloading with an example.

8+ MARKS
Definition: A constructor is a special member of a class that initialises an object when it is created.

Features of constructors

  1. The constructor name must be the same as the class name.
  2. It does not have a return type, not even void.
  3. It is called automatically when an object is created using new.
  4. It is mainly used to give initial values to instance variables.
  5. A constructor can receive parameters.
  6. A class can contain more than one constructor.
  7. If no constructor is written, Java supplies a default no-argument constructor.

Types

  • No-argument constructor: Takes no parameters.
  • Parameterized constructor: Receives values from the object-creation statement.

Constructor overloading

Constructor overloading means defining more than one constructor in the same class with different parameter lists. The compiler selects the constructor that matches the arguments.

class Box {
    double width, height, depth;

    Box() {
        width = height = depth = 1;
    }

    Box(double w, double h, double d) {
        width = w;
        height = h;
        depth = d;
    }

    Box(double side) {
        width = height = depth = side;
    }

    void volume() {
        System.out.println(width * height * depth);
    }
}
class Demo {
    public static void main(String[] args) {
        Box b1 = new Box();
        Box b2 = new Box(2, 3, 4);
        Box b3 = new Box(5);

        b1.volume();
        b2.volume();
        b3.volume();
    }
}

Output

1.0
24.0
125.0

Explanation

  1. The first constructor sets all dimensions to 1.
  2. The second constructor receives three dimensions.
  3. The third constructor receives one side and creates a cube.
  4. Each object calls a constructor based on the supplied arguments.

Advantages: Objects can be created in different ways, initialisation becomes flexible and code duplication is reduced.

Q2

Write a Java program to demonstrate the use of the this keyword.

8+ MARKS
Definition: The this keyword is a reference to the current object — the object whose method or constructor is running.

Uses of this

  1. It refers to the current object.
  2. It distinguishes instance variables from local variables or parameters with the same name.
  3. It can call another constructor in the same class using this().
  4. It can call a current class method.
  5. It can pass the current object as an argument.
  6. It can return the current object from a method.

Program

class Student {
    int age;
    String name;

    Student(int age, String name) {
        this.age = age;
        this.name = name;
    }

    void display() {
        System.out.println("Name: " + this.name);
        System.out.println("Age: " + this.age);
    }

    public static void main(String[] args) {
        Student s = new Student(20, "Anu");
        s.display();
    }
}

Output

Name: Anu
Age: 20

Explanation

  1. The class contains age and name instance variables.
  2. The constructor also receives parameters with the same names.
  3. this.age refers to the instance variable.
  4. age refers to the constructor parameter.
  5. The same rule applies to name.
  6. The display() method prints the current object's values.
Remember: this.variable = current object's variable. variable = local parameter.
Q3

Compare method overloading and method overriding with suitable examples.

8+ MARKS
Method overloading: Defining methods with the same name but different parameter lists in one class or an inherited class context.
Method overriding: A subclass provides its own implementation of an inherited instance method with a compatible signature.

Method overloading example

class Calculator {
    int add(int a, int b) {
        return a + b;
    }

    int add(int a, int b, int c) {
        return a + b + c;
    }

    public static void main(String[] args) {
        Calculator c = new Calculator();
        System.out.println(c.add(2, 3));
        System.out.println(c.add(2, 3, 4));
    }
}

Method overriding example

class Animal {
    void sound() {
        System.out.println("Animal sound");
    }
}
class Dog extends Animal {
    @Override
    void sound() {
        System.out.println("Dog barks");
    }
}
class Test {
    public static void main(String[] args) {
        Animal a = new Dog();
        a.sound();
    }
}

Class and object

A class is a blueprint that defines fields and methods. An object is an instance of that class created in memory.
class Student {
    String name;
    void show() {
        System.out.println(name);
    }
}
class Demo {
    public static void main(String[] args) {
        Student s = new Student();
        s.name = "Ravi";
        s.show();
    }
}

Declaring an object

  1. Reference declaration: Student s;
  2. Object creation: s = new Student();
  3. Combined: Student s = new Student();
  4. Use the dot operator to access members: s.name and s.show().

Assigning object references

When one reference variable is assigned to another, both references point to the same object. Assignment does not create a second object.

Student s1 = new Student();
Student s2 = s1; // both refer to same object

Methods

A method is a named block of code that performs a task. It can accept parameters and return a value. A method declared with void does not return a value.

Inheritance

Inheritance allows a child class to receive accessible members from a parent class. Java uses extends. Common class forms are single, multilevel and hierarchical inheritance. Multiple inheritance of classes is not supported; interfaces provide a way for a class to implement multiple contracts.

Keywords

Keywords are reserved words with special meaning in Java. Examples: class, public, static, void, int, if, else, new, this, extends and return. They cannot be used as identifiers.

Q1

Explain the steps to create and use a user-defined package in Java.

8+ MARKS
Definition: A package is a group of related classes and interfaces. It is used to organise Java programs and control access.

Advantages

  1. Organises related classes and interfaces.
  2. Avoids class-name conflicts between projects.
  3. Supports code reuse.
  4. Provides access protection.
  5. Makes large programs easier to maintain.
  6. Helps divide a project into logical sections.

Steps to create a package

  1. Choose a package name, for example mypack.
  2. Write the package statement as the first non-comment statement in the source file.
  3. Declare the class as public if it must be accessed from outside the package.
  4. Save the source file in the matching folder or compile with the destination option.
  5. Compile the class.
  6. Import the class in another program.
  7. Create its object and call its public methods.

Program 1 – Create a package class

// File: mypack/Message.java
package mypack;

public class Message {
    public void show() {
        System.out.println("Welcome to Java Package");
    }
}

Program 2 – Use the package

// File: Test.java
import mypack.Message;

class Test {
    public static void main(String[] args) {
        Message m = new Message();
        m.show();
    }
}

Compile and run

javac mypack/Message.java
javac Test.java
java Test

Output

Welcome to Java Package

Conclusion: User-defined packages organise classes and make Java projects reusable and easier to manage.

Write a Java program to demonstrate multiple inheritance using interfaces.

Definition: Multiple inheritance means receiving features or contracts from more than one parent. Java does not allow a class to extend two classes, but a class can implement multiple interfaces.

Printing
Showing

Explanation

  1. Printable declares the print() method.
  2. Showable declares the show() method.
  3. Demo implements both interfaces.
  4. Demo defines both methods.
  5. The main method creates one Demo object.
  6. The object calls both methods.

Conclusion: Interfaces allow a Java class to implement multiple contracts, providing multiple inheritance of type.

Q3

Analyse the differences between throw and throws in exception handling.

8+ MARKS
Exception: An exception is an object that represents an error or unexpected condition during program execution. Exception handling helps a program respond to the problem.

Exception-handling keywords

  • try: contains code that may cause an exception.
  • catch: handles an exception.
  • throw: manually throws an exception object.
  • throws: declares exceptions that a method may pass to its caller.
  • finally: contains cleanup code that normally runs after try/catch, even when an exception is thrown or a return is used.

throw

  • Used inside a method or block.
  • Used to explicitly throw an exception object.
  • Followed by an exception object.
  • Example: throw new IllegalArgumentException("Invalid");

throws

  • Used in a method declaration.
  • Declares the exception types a method may throw.
  • Followed by exception class names.
  • Important for checked exceptions that are not handled inside the method.
  • Example: void read() throws IOException

Q1

Explain the life cycle of a thread with a neat diagram.

8+ MARKS
Definition: The thread life cycle describes the different states a thread passes through from creation until its execution finishes.

Thread states

  1. New: A Thread object is created, but start() has not been called.
  2. Runnable: The thread has started and is ready to run or waiting for CPU time.
  3. Running: The thread's run() method is executing. This is a helpful learning description; Java officially includes ready and running in RUNNABLE.
  4. Blocked: The thread is waiting to get a monitor lock.
  5. Waiting: The thread waits for another thread to perform an action, for example after join() without a timeout.
  6. Timed Waiting: The thread waits for a specified time, for example during sleep() or timed wait().
  7. Terminated: The run() method has finished or ended due to an uncaught error.

TOPIC

Multithreaded concepts, file classes, stream classes and String handling

8+ MARK NOTES

Multithreading

Multithreading means performing multiple paths of execution concurrently inside one process. It improves responsiveness. A process is a program in execution; a thread is an execution path inside that process. Process-based multitasking runs multiple programs, while thread-based multitasking runs multiple tasks within one program.

Creating threads

Two common ways are extending Thread and implementing Runnable. Override run() with the task and call start() to begin a new thread. Calling run() directly is just a normal method call.

class Task implements Runnable {
    public void run() {
        System.out.println("Task running");
    }
}
class Demo {
    public static void main(String[] args) {
        Thread t = new Thread(new Task());
        t.start();
    }
}

Synchronization

Synchronization controls access to shared data. It prevents two threads from entering a synchronized section protected by the same object lock at the same time. This helps prevent race conditions.

class Counter {
    int count = 0;
    synchronized void increase() {
        count++;
    }
}

File class

The File class represents a file or directory path. Common methods include exists(), isFile(), isDirectory(), getName(), getPath(), length(), delete(), mkdir(), mkdirs(), list() and listFiles().

Stream classes

Java I/O is based on four main abstract classes: InputStream, OutputStream, Reader and Writer. Subclasses provide file and other input/output operations.

String handling

String is a sequence of characters. String objects are immutable: once created, their contents cannot be changed. Common methods are length(), charAt(), equals(), compareTo(), substring(), concat(), toUpperCase(), toLowerCase(), trim() and indexOf(). Use equals() to compare contents; == compares references.

String word = "Java";

System.out.println(word.charAt(0));      // J
System.out.println(word.toUpperCase());  // JAVA
System.out.println(word.equals("Java"));// true

StringBuffer and StringBuilder

  • StringBuffer: Mutable character sequence; its methods are synchronized and useful when shared thread-safe modification is needed.
  • StringBuilder: Mutable character sequence; not synchronized and generally faster when thread safety is not required.
  • Both support append(), insert(), delete(), replace(), reverse(), length() and capacity().

Q1

Explain the event delegation model in Java AWT with an example.

8+ MARKS
Definition: The event delegation model is Java's method of handling user actions. A component generates an event and sends it to a registered listener that handles the event.

Main parts

  1. Event source: The component that generates the event, such as a Button.
  2. Event object: Contains information about the event, such as ActionEvent.
  3. Event listener: An object that receives and handles the event, such as ActionListener.

Working steps

  1. Create the GUI component.
  2. Implement the required listener interface.
  3. Register the listener with the event source using a method such as addActionListener().
  4. The user performs an action, such as clicking the button.
  5. The source creates an event object.
  6. The registered listener receives the event.
  7. The listener's event-handling method runs, for example actionPerformed().

Diagram

USER CLICKS BUTTON | v EVENT SOURCE Button | v EVENT OBJECT ActionEvent | v EVENT LISTENER ActionListener | v actionPerformed() | v ACTION IS DONE

Program

import java.awt.*;
import java.awt.event.*;

class ButtonDemo extends Frame
        implements ActionListener {

    Button b;

    ButtonDemo() {
        b = new Button("Click Me");
        add(b);

        b.addActionListener(this);

        setLayout(new FlowLayout());
        setSize(300, 200);
        setVisible(true);
    }

    public void actionPerformed(ActionEvent e) {
        setTitle("Button Clicked");
    }

    public static void main(String[] args) {
        new ButtonDemo();
    }
}

Explanation

  1. Frame creates the window.
  2. Button creates a clickable control.
  3. ActionListener is implemented by the class.
  4. addActionListener(this) registers the current object.
  5. When the button is clicked, actionPerformed() is called.
  6. The window title changes.

Conclusion: Event delegation separates event generation from event handling and makes GUI programs easier to organise.

Q2

Write a Java program to create a simple login form using Swing components.

8+ MARKS
Definition: Swing is a Java GUI library used to create windows and user-interface components such as labels, text fields and buttons.

Components used

  • JFrame – creates the login window.
  • JLabel – displays Username and Password text.
  • JTextField – accepts username.
  • JPasswordField – accepts password input.
  • JButton – creates the Login button.
  • ActionListener – handles the button click.

Java program

import javax.swing.*;
import java.awt.*;
import java.awt.event.*;

class LoginForm {
    public static void main(String[] args) {

        JFrame f = new JFrame("Login Form");

        JLabel l1 = new JLabel("Username:");
        JTextField t1 = new JTextField(15);

        JLabel l2 = new JLabel("Password:");
        JPasswordField t2 = new JPasswordField(15);

        JButton b = new JButton("Login");
        JLabel result = new JLabel("");

        f.setLayout(new FlowLayout());

        f.add(l1);
        f.add(t1);
        f.add(l2);
        f.add(t2);
        f.add(b);
        f.add(result);

        b.addActionListener(new ActionListener() {
            public void actionPerformed(ActionEvent e) {
                String user = t1.getText();
                String pass =
                    new String(t2.getPassword());

                if (user.equals("admin") &&
                    pass.equals("1234")) {
                    result.setText("Login Successful");
                } else {
                    result.setText("Invalid Login");
                }
            }
        });

        f.setSize(300, 220);
        f.setDefaultCloseOperation(
            JFrame.EXIT_ON_CLOSE);
        f.setVisible(true);
    }
}

Expected output

LOGIN FORM Username: [____________] Password: [____________] [ Login ] Login Successful

Explanation

  1. Import Swing and event packages.
  2. Create the JFrame window.
  3. Create username and password labels and fields.
  4. Create the Login button.
  5. Add all components to the frame.
  6. Register an ActionListener for the button.
  7. When clicked, getText() reads the username and getPassword() reads the password.
  8. The if condition checks the entered values and displays the result.
This is an exam demonstration with sample credentials. A real application must not store passwords directly in source code.

Conclusion: Swing components can be combined with event handling to create a simple interactive login form.

Q3

Analyse the differences between AWT and Swing components.

8+ MARKS
AWT: Abstract Window Toolkit is Java's original GUI toolkit. Swing: A richer GUI component library built on top of AWT.

AWT features

  • Used to create windows and basic GUI components.
  • Uses native platform peers for its heavyweight components.
  • Provides Button, Label, TextField, Frame and other controls.
  • Its appearance can depend on the operating system.
  • Classes are mainly in the java.awt package.

Swing features

  • Provides more GUI components than AWT.
  • Most Swing components are lightweight.
  • Provides JButton, JLabel, JTextField, JFrame and JPasswordField.
  • Supports pluggable look and feel.
  • Classes are mainly in javax.swing.
  • Uses AWT infrastructure for events, graphics and top-level windows.

Layout managers

  • FlowLayout: places components left to right and then moves to the next line.
  • BorderLayout: divides the area into North, South, East, West and Center.
  • GridLayout: arranges components in equal-sized rows and columns.
  • CardLayout: shows one component/card at a time.
  • GridBagLayout: flexible grid arrangement.

MVC architecture

MVC means Model–View–Controller. It separates an application into data, display and user-action handling.
  • Model: stores data and component state. Example: whether a checkbox is selected.
  • View: controls how data is displayed. Example: the checkbox's appearance.
  • Controller: handles user actions and updates the model. Example: responds to a click.

Advantages: separation of responsibilities, easier maintenance, easier testing, flexibility and code reuse.
