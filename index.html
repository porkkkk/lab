UNIT I – AN OVERVIEW OF JAVA

QUESTION 1 • 8 MARKS

Explain the principles of Object-Oriented Programming with examples.

Definition

Object-Oriented Programming (OOP) is a programming method based on classes and objects. It makes programs easy to understand and reuse.

Four main principles

1. Encapsulation

  • Combining data and methods in one class.
  • Protects data from unwanted access.
  • Example: Bank account.

2. Inheritance

  • One class gets properties of another class.
  • It saves time and reuses code.
  • Example: Dog inherits from Animal.

3. Polymorphism

  • Polymorphism means many forms.
  • One method name can perform different tasks.
  • Example: Method overloading.

4. Abstraction

  • Hides unnecessary details.
  • Shows only important information.
  • Example: Driving a car without knowing the engine details.

Simple example

class Animal {
    void eat() {
        System.out.println("Eating");
    }
}

class Dog extends Animal {
    void bark() {
        System.out.println("Barking");
    }
}

class Demo {
    public static void main(String[] args) {
        Dog d = new Dog();
        d.eat();
        d.bark();
    }
}
Output:
Eating
Barking
Conclusion: OOP makes Java programs reusable, secure and easy to maintain.
QUESTION 2 • 8 MARKS

Write a Java program to find the largest of three numbers using if-else.

Definition

The if-else statement is used to make decisions based on conditions.

Program

class Largest {
    public static void main(String[] args) {

        int a = 10;
        int b = 25;
        int c = 15;

        if (a > b && a > c) {
            System.out.println("A is largest");
        }
        else if (b > c) {
            System.out.println("B is largest");
        }
        else {
            System.out.println("C is largest");
        }
    }
}
Output:
B is largest

Explanation

  1. Declare three numbers A, B and C.
  2. First condition checks whether A is largest.
  3. Second condition checks whether B is largest.
  4. Otherwise C is largest.
  5. Print the largest number.
Conclusion: The if-else statement helps to find the largest number by checking conditions.
QUESTION 3 • 8 MARKS

Differentiate between while, do-while and for loops with examples.

Definition

A loop is used to repeat a block of code multiple times.

1. While loop

  • Checks the condition first.
  • Executes while the condition is true.
int i = 1;
while (i <= 3) {
    System.out.println(i);
    i++;
}

2. Do-while loop

  • Executes the code first.
  • Checks the condition later.
  • Runs at least once.
int i = 1;
do {
    System.out.println(i);
    i++;
} while (i <= 3);

3. For loop

  • Used when repetitions are known.
  • Contains initialization, condition and update.
for (int i = 1; i <= 3; i++) {
    System.out.println(i);
}

Difference

WhileDo-whileFor
Condition firstCondition lastCondition first
May run zero timesRuns at least onceMay run zero times
Unknown repetitionsAt least one executionKnown repetitions
Conclusion: All three loops are used to repeat statements in Java.

UNIT II – INTRODUCING CLASSES

QUESTION 4 • 8 MARKS

Describe constructors in Java and explain constructor overloading with an example.

Definition

A constructor is a special member of a class. It is automatically called when an object is created.

Features

  • Constructor name is the same as the class name.
  • It has no return type.
  • It initializes objects.
  • It is called automatically.

Types of constructors

1. Default constructor: A constructor without parameters.

2. Parameterized constructor: A constructor with parameters.

Constructor overloading

Creating more than one constructor with different parameters in the same class is called constructor overloading.

Program

class Student {

    Student() {
        System.out.println("Welcome");
    }

    Student(int age) {
        System.out.println(age);
    }

    public static void main(String[] args) {

        Student s1 = new Student();
        Student s2 = new Student(20);
    }
}
Output:
Welcome
20

Explanation

  • First constructor has no parameters.
  • Second constructor has one parameter.
  • Both have the same name.
  • Java selects the constructor based on the arguments.
Conclusion: Constructors initialize objects. Constructor overloading provides different ways to initialize objects.
QUESTION 5 • 8 MARKS

Write a Java program to demonstrate the use of this keyword.

Definition

The this keyword refers to the current object in Java.

Uses

  • Refers to current class variables.
  • Removes confusion between variables.
  • Calls another constructor using this().
  • Calls current class methods.

Program

class Student {

    int age;

    Student(int age) {
        this.age = age;
    }

    void display() {
        System.out.println(age);
    }

    public static void main(String[] args) {

        Student s = new Student(20);
        s.display();
    }
}
Output:
20

Explanation

  • Student is the class name.
  • Age is an instance variable.
  • The constructor receives age.
  • this.age refers to the class variable.
  • age refers to the parameter.
Conclusion: The this keyword refers to the current object and avoids confusion between variables.
QUESTION 6 • 8 MARKS

Compare method overloading and method overriding with suitable examples.

Method overloading

Using the same method name with different parameters in the same class is called method overloading.

class Demo {

    void show(int a) {
        System.out.println(a);
    }

    void show(String b) {
        System.out.println(b);
    }

    public static void main(String[] args) {
        Demo d = new Demo();
        d.show(10);
        d.show("Java");
    }
}

Method overriding

When a child class gives its own definition to a parent class method, it is called method overriding.

class Animal {
    void sound() {
        System.out.println("Animal sound");
    }
}

class Dog extends Animal {
    void sound() {
        System.out.println("Dog barks");
    }

    public static void main(String[] args) {
        Dog d = new Dog();
        d.sound();
    }
}

Differences

OverloadingOverriding
Different parametersSame method signature
Usually same classParent and child classes
Compile-timeRuntime
Inheritance not neededInheritance needed
Conclusion: Both methods support polymorphism and make Java programs flexible.

UNIT III – PACKAGES AND INTERFACES

QUESTION 7 • 8 MARKS

Explain the steps to create and use a user-defined package in Java.

Definition

A package is a collection of related classes and interfaces. It helps to organize Java programs.

Advantages

  • Organizes classes.
  • Avoids naming conflicts.
  • Provides access protection.
  • Makes programs easy to maintain.

Steps to create a package

Step 1: Create a file named Student.java.

package MyPack;

public class Student {

    public void display() {
        System.out.println("Welcome to Package");
    }
}

Step 2: Create Demo.java.

import MyPack.Student;

class Demo {

    public static void main(String[] args) {

        Student s = new Student();
        s.display();
    }
}

Step 3: Compile and run.

javac -d . Student.java
javac Demo.java
java Demo
Output:
Welcome to Package

Explanation

  • package creates a package.
  • public class creates a class.
  • import imports the class.
  • new creates an object.
  • The object calls the display method.
Conclusion: Packages group related classes and make programs easy to manage.
QUESTION 8 • 8 MARKS

Write a Java program to demonstrate multiple inheritance using interfaces.

Definition

An interface is a blueprint that contains method declarations. A class uses the implements keyword to use an interface.

Important points

  • Interface provides abstraction.
  • A class can implement multiple interfaces.
  • It supports multiple inheritance of type.
  • Interface methods are public and abstract by default.
  • It improves code flexibility.

Program

interface A {
    void show();
}

interface B {
    void display();
}

class Demo implements A, B {

    public void show() {
        System.out.println("Interface A");
    }

    public void display() {
        System.out.println("Interface B");
    }

    public static void main(String[] args) {

        Demo d = new Demo();

        d.show();
        d.display();
    }
}
Output:
Interface A
Interface B

Explanation

  • A and B are two interfaces.
  • Demo implements both interfaces.
  • Demo defines both methods.
  • The object calls both methods.
Conclusion: Java supports multiple inheritance using interfaces.
QUESTION 9 • 8 MARKS

Explain exception handling in Java. Differentiate between throw and throws.

Definition

Exception handling is used to handle errors during program execution. It prevents abnormal program termination when an error can be handled.

Five important keywords

  • try: Contains risky code.
  • catch: Handles the error.
  • finally: Used for cleanup.
  • throw: Manually throws an exception.
  • throws: Declares possible exceptions in a method.

Simple program

class Demo {

    public static void main(String[] args) {

        try {
            int a = 10 / 0;
        }
        catch (ArithmeticException e) {
            System.out.println("Division Error");
        }
        finally {
            System.out.println("Completed");
        }
    }
}
Output:
Division Error
Completed

Difference between throw and throws

throwthrows
Throws an exception manuallyDeclares an exception
Inside method or blockIn method declaration
Followed by exception objectFollowed by exception class
One exception object at a timeCan declare multiple exceptions

Example:

throw new ArithmeticException();

void show() throws IOException {
    // File operation
}
Conclusion: Exception handling helps programs handle errors safely. Throw is used to throw an exception, while throws declares it.

Definition

A thread is a small unit of execution. Thread life cycle describes the different states of a thread.

Five main states

1. New: Thread object is created.

2. Runnable: Thread is ready to run.

3. Running: Thread executes its work.

4. Blocked / Waiting: Thread waits for a resource or another thread.

5. Terminated: Thread finishes execution.

Important thread methods

  • start() – Starts the thread.
  • run() – Contains thread work.
  • sleep() – Pauses the thread.

  • isAlive() – Checks thread status.

QUESTION 11 • 8 MARKS

Write a Java program to read the contents of a file using FileReader.

Definition

FileReader is a Java class used to read characters from a text file.

Important points

  • It belongs to the java.io package.
  • It reads text files.
  • It reads one character at a time using read().
  • It returns -1 at the end of the file.
  • close() closes the file.

Program

import java.io.*;

class Demo {

    public static void main(String[] args) {

        try {
            FileReader f =
                new FileReader("test.txt");

            int ch;

            while ((ch = f.read()) != -1) {
                System.out.print((char) ch);
            }

            f.close();
        }
        catch (IOException e) {
            System.out.println("File Error");
        }
    }
}

Suppose test.txt contains: Welcome to Java

Output:
Welcome to Java

Explanation

  • Import the java.io package.
  • FileReader opens the file.
  • read() reads characters.
  • Loop continues until -1.
  • close() closes the file.
Conclusion: FileReader is used to read character data from a text file.

UNIT V – AWT AND SWING

QUESTION 13 • 8 MARKS

Explain the event delegation model in Java AWT with an example.

Definition

The Event Delegation Model is used to handle user actions like button clicks and mouse movements.

Three main parts

1. Event Source

The component that generates an event. Example: Button.

2. Event Object

Contains information about the event. Example: ActionEvent.

3. Event Listener

Receives and handles the event. Example: ActionListener.

Working

  1. User clicks a button.
  2. Button generates an event.
  3. Event object is created.
  4. Listener receives the event.
  5. Required action is performed.

Program

import java.awt.*;
import java.awt.event.*;

class Demo extends Frame
implements ActionListener {

    Button b;
    Label l;

    Demo() {

        b = new Button("Click Me");
        l = new Label("Welcome");

        setLayout(new FlowLayout());

        add(b);
        add(l);

        b.addActionListener(this);

        setSize(300, 200);
        setVisible(true);
    }

    public void actionPerformed(ActionEvent e) {
        l.setText("Button Clicked");
    }

    public static void main(String[] args) {
        new Demo();
    }
}

Explanation

  • Button is the event source.
  • ActionEvent is the event object.
  • ActionListener handles the event.
  • Clicking the button changes the label.
Conclusion: Event Delegation Model makes event handling simple and organized.
QUESTION 14 • 8 MARKS

Write a Java program to create a simple login form using Swing components.

Definition

Swing is a Java GUI toolkit used to create windows, buttons, labels and text fields.

Important components

  • JFrame – Creates a window.
  • JLabel – Displays text.
  • JTextField – Accepts username.
  • JPasswordField – Accepts password.
  • JButton – Creates login button.

Program

import javax.swing.*;
import java.awt.*;
import java.awt.event.*;

class Login extends JFrame
implements ActionListener {

    JTextField user;
    JPasswordField pass;
    JButton b;
    JLabel result;

    Login() {

        setTitle("Login Form");
        setLayout(new FlowLayout());

        add(new JLabel("Username"));

        user = new JTextField(15);
        add(user);

        add(new JLabel("Password"));

        pass = new JPasswordField(15);
        add(pass);

        b = new JButton("Login");
        add(b);

        result = new JLabel("");
        add(result);

        b.addActionListener(this);

        setSize(300, 250);
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        setVisible(true);
    }

    public void actionPerformed(ActionEvent e) {

        if (user.getText().equals("admin") &&
            new String(pass.getPassword()).equals("123")) {

            result.setText("Login Successful");
        }
        else {
            result.setText("Invalid Login");
        }
    }

    public static void main(String[] args) {
        new Login();
    }
}

Explanation

  • JFrame creates the login window.
  • JTextField accepts username.
  • JPasswordField accepts password.
  • JButton creates the login button.
  • ActionListener handles the click.
  • The program checks the username and password.
Conclusion: Swing components help to create a simple and user-friendly login form.

Analyze the differences between AWT and Swing components.

What is AWT?

AWT stands for Abstract Window Toolkit. It is used to create Java graphical user interfaces.

What is Swing?

Swing is a Java GUI toolkit built on top of AWT. It provides more flexible components.

Features of AWT

  • Uses native GUI components.
  • Has fewer components.
  • Uses operating system controls.
  • Package: java.awt.

Features of Swing

  • Provides more GUI components.
  • Mostly uses lightweight components.
  • Supports different look and feel.
  • Easy to customize.
  • Package: javax.swing.
