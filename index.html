Explain recursion with an example.
−

Definition: Recursion is a process in which a function calls itself to solve a problem. A recursive function must have a stopping condition called the base condition.

Important parts

  1. Recursive function: A function that calls itself.
  2. Base condition: Stops the function.
  3. Recursive call: Calls the same function again.

Syntax

def function_name():
    if condition:
        return
    function_name()

Example: Factorial program

def factorial(n):
    if n == 1:
        return 1
    else:
        return n * factorial(n - 1)

print(factorial(5))
120

Explanation

Factorial of 5 is:

5 × 4 × 3 × 2 × 1 = 120

Working:

factorial(5)
     |
5 * factorial(4)
     |
4 * factorial(3)
     |
3 * factorial(2)
     |
2 * factorial(1)
     |
     1

Advantages

  • Reduces repeated code.
  • Useful for mathematical problems.
  • Makes some programs shorter.
  • Useful for tree and directory problems.

Disadvantages

  • Uses more memory for function calls.
  • Can be slower than loops.
  • Missing a base condition may cause infinite recursion.
Conclusion: Recursion is a technique where a function calls itself until the base condition is reached.

Explain execution-flow hijacking.
−

Definition: Execution-flow hijacking is a technique in which an attacker changes the normal execution path of a program so that unwanted or malicious code runs. In simple words, the attacker tries to make a program run the wrong code.

How it works

  1. A program normally searches for the files or libraries it needs.
  2. An attacker finds a weak point in this process.
  3. The attacker may place an untrusted file in a location the program searches.
  4. The program may load the wrong file.
  5. Unwanted code may run instead of the expected code.

Common methods

1. DLL hijacking

An application may load an untrusted DLL file instead of the correct one.

2. PATH hijacking

An application may run an unwanted program because it finds it in an unsafe search location.

3. Library hijacking

A program may load a harmful library instead of the genuine library.

Security risks

  • Unauthorized code execution.
  • Data theft.
  • Malware infection.
  • Privilege escalation.
  • System damage.

Detection methods

  • Monitor unusual program activity.
  • Check unexpected libraries.
  • Review application directories.
  • Check file permissions.
  • Use antivirus and endpoint protection.
  • Monitor suspicious file changes.

Prevention

  • Use trusted libraries.
  • Keep software updated.
  • Restrict folder permissions.
  • Avoid unsafe search paths.
  • Use application security tools.
Conclusion: Execution-flow hijacking changes the normal program execution path. Proper file permissions and trusted libraries help prevent it.

Explain Alternate Data Streams (ADS) and their detection.
−

Definition: Alternate Data Streams (ADS) are a feature of the NTFS file system in Windows. They allow additional data to be stored along with a normal file. In simple words, one file can contain extra hidden information.

Features of ADS

  • ADS is supported by the NTFS file system.
  • Extra information can be attached to a file.
  • The extra data may not appear in normal directory listings.
  • Attackers may misuse ADS to hide information.
  • Digital forensic investigators check ADS during investigations.

Example

A normal file:

document.txt

An additional stream can be attached to it:

document.txt:hidden

How ADS can be misused

  • Hiding unwanted files.
  • Storing suspicious information.
  • Hiding data from normal file listings.
  • Making forensic investigation difficult.

Detection methods

1. Using Command Prompt

dir /r

This displays alternate data streams in a directory.

2. Using PowerShell

Get-Item document.txt -Stream *

This lists streams attached to the specified file.

3. Use forensic tools

Digital forensic tools can help identify and examine hidden streams.

4. Monitor unusual files

Check files with unexpected additional streams.

Prevention

  • Scan files regularly.
  • Use updated antivirus software.
  • Monitor suspicious file activity.
  • Restrict unauthorized access.
  • Perform regular forensic checks.
Conclusion: ADS is an NTFS feature used to store additional data. Detecting hidden streams helps identify suspicious files and activities.

Explain how to protect passwords stored in web browsers.
−

Definition: Browser password protection means keeping saved usernames and passwords safe from unauthorized access. Browsers such as Google Chrome allow users to save login details.

Working of Chrome password management

  1. The user saves login details in Chrome.
  2. Chrome encrypts the password.
  3. The encrypted data is stored in a password database.
  4. Chrome uses the saved information when the user visits the website.

Chrome password database

  • Origin URL: Website address.
  • Username: Saved login name.
  • Password value: Encrypted password.
  • Date created: Time when the credential was saved.

The database uses SQLite format.

Encryption methods

  • Windows: Uses Data Protection API (DPAPI). Encryption keys are linked to the user account.
  • macOS: Uses Keychain.
  • Linux: Uses system keyring services.

Security threats

  • Malware may try to steal passwords.
  • Attackers may steal browser cookies.
  • Unauthorized users may access browser profiles.
  • Weak passwords may be guessed.
  • Shared computers may expose saved credentials.

Protection methods

  1. Use strong and unique passwords.
  2. Enable Multi-Factor Authentication (MFA).
  3. Avoid saving passwords on shared computers.
  4. Keep browsers updated.
  5. Use antivirus protection.
  6. Check saved passwords regularly.
  7. Remove unused credentials.

Role in digital forensics

Investigators may examine browser databases, login records and user profile information with proper authorization.

Conclusion: Browser password protection helps prevent credential theft and unauthorized access.

Types of network sniffing

1. Passive sniffing

  • Is difficult to detect.
  • Mainly used in hub-based networks.

2. Active sniffing

  • Involves modifying network traffic to capture packets.
  • Commonly used in switched networks.

  2. Packet filtering: Selects the required packets.

Security risks

  • Password theft.
  • Data theft.

  2. Use SSH instead of Telnet.
  3. Disable insecure protocols.
  4. Use VPN for remote access.
  5. Use strong encryption.
  6. Enable Multi-Factor Authentication.
  7. Use secure Wi-Fi such as WPA3.

Techniques used

Sends harmless network packets to confuse traffic analysis.

Advantages

  • Improves network security.
Conclusion: Deceptive network connections use fake network activities to detect attackers and improve network protection.

Explain honeypot files and folders.
−

Definition: Honeypot files and folders are fake but realistic-looking files created to attract unauthorized users. They do not contain real confidential information. They help detect suspicious activities.

Purpose

  • Detect unauthorized access.
  • Identify insider threats.
  • Protect valuable information.
  • Collect digital evidence.
  • Monitor suspicious activities.

How it works

Step 1 – Create fake files

The administrator creates files such as:

Employee_Salary.xlsx
Passwords.txt
Company_Records.docx

Step 2 – Place files in suitable locations

These files are placed in shared folders or commonly searched directories.

Step 3 – Enable monitoring

Security software watches the files.

Step 4 – Generate alerts

When someone accesses a honeypot file, an alert is sent to the administrator.

Step 5 – Investigate the activity

The administrator checks the logs to identify suspicious access.

Applications

  1. Digital forensics.
  2. Insider threat detection.
  3. Malware analysis.
  4. Incident response.
  5. Network security.

Advantages

  • Detects unauthorized access early.
  • Collects useful evidence.
  • Helps identify suspicious users.
  • Improves system security.
  • Protects real confidential data.

Limitations

  • Requires continuous monitoring.
  • Experienced attackers may identify fake files.
  • Needs proper access permissions.
  • Alerts must be checked regularly.

Example

A company creates a fake file called Employee_Salary.xlsx. When an unauthorized employee opens the file, the system records the username and access time and sends an alert to the security administrator.

Conclusion: Honeypot files and folders help detect unauthorized access and collect useful evidence during security investigations.
