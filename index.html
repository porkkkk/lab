An Overview of Java

Learn Java basics, OOP, data types, variables, arrays, operators and control statements.

1. Introduction to Java

Definition: Java is a high-level, object-oriented programming language used to develop many types of applications.

  1. Developed by James Gosling at Sun Microsystems.
  2. Originally called Oak.
  3. Renamed Java and released in 1995.
  4. Platform-independent with JVM.
  5. Supports object-oriented programming.
  6. Secure, robust and portable.
  7. Supports multithreading.
  8. Follows WORA: Write Once, Run Anywhere.
Java source code is compiled into bytecode. JVM runs the bytecode.

7. OOP principles

Definition: Object-Oriented Programming is a method of writing programs using classes and objects. Its four main principles are:

1. Encapsulation

Combining data and methods in one class and protecting data from direct access. Example: private bank balance with public deposit method.

2. Inheritance

One class receives fields and methods from another class. It uses extends. Example: Dog extends Animal.

3. Polymorphism

One method name can work in different ways. It is achieved through overloading and overriding.

4. Abstraction

Hiding internal details and showing only important features. It uses abstract classes and interfaces.

Advantages: Code reuse, data protection, easy maintenance and less repetition.

Memory trick: E-I-P-A = Encapsulation, Inheritance, Polymorphism, Abstraction.

Introducing Classes

Classes, objects, references, methods, constructors, this and inheritance.

5 MARKS

1. Class and object

Class: A class is a blueprint used to create objects.

Object: An object is an instance of a class. It has data and behaviour.

class Student {
  int age=20;
  void show() {
    System.out.println(age);
  }
}
class Demo {
  public static void main(String[] args) {
    Student s=new Student();
    s.show();
  }
}
Output
20

Student is the class. The variable s refers to the created object.

5 MARKS

2. Declaring objects

Object creation has two main parts:

  1. Declaration creates a reference variable.
  2. new creates the object and calls its constructor.
Student s;        // declaration
s = new Student(); // object creation

Combined form: Student s = new Student();

5 MARKS

3. Object reference assignment

When one reference is assigned to another, both can refer to the same object.

Student s1 = new Student();
Student s2 = s1;

No second object is created. A change through one reference can be seen through the other.

Methods reduce repetition, support reuse and make programs easier to understand.

class Demo {

  public static void main(String[] args) {
    new Demo().add();

}

5. Constructors and constructor overloading

Definition: A constructor is a special member that runs when an object is created. Its name is the same as the class name and it has no return type.

Types: No-argument constructor and parameterized constructor. If no constructor is written, Java provides a default constructor.

Constructor overloading: Writing more than one constructor with different parameter lists in one class.

class Student {
  Student() {
    System.out.println("No argument");
  }
  Student(int age) {
    System.out.println("Age: " + age);
  }
  public static void main(String[] args) {
    new Student();
    new Student(20);
  }
}
Output
No argument
Age: 20

The first object calls the no-argument constructor. The second calls the constructor that accepts an integer.

5 MARKS

6. this keyword

Definition: this refers to the current object.

It is used to distinguish instance variables from parameters, call another constructor and refer to current object methods.

class Student {
  int age;
  Student(int age) {
    this.age = age;
  }
  public static void main(String[] args) {
    Student s = new Student(20);
    System.out.println(s.age);
  }
}
Output
20

this.age means the object's variable; age means the constructor parameter.

8 MARKS

7. Inheritance

Definition: Inheritance allows a child class to use accessible fields and methods of a parent class. It uses extends.

Types: Single, multilevel and hierarchical. Multiple inheritance of classes is not supported directly; multiple interfaces can be implemented.

class Animal {
  void eat() {
    System.out.println("Eating");
  }
}
class Dog extends Animal {
  public static void main(String[] args) {
    Dog d = new Dog();
    d.eat();
  }
}
Output
Eating

Dog inherits the eat() method from Animal.

Advantages: Code reuse, less repetition, easier maintenance and support for runtime polymorphism.

Can be in one class.Needs inheritance.

Overloading changes the parameter list. Overriding provides a new implementation of an inherited method.

Packages and Interfaces

Package creation, access control, interfaces and exception handling.
5 & 8 MARKS
8 MARKS

1. Packages

Definition: A package is a group of related classes and interfaces.

Types: Built-in packages and user-defined packages.

Examples: java.lang, java.util, java.io, java.awt.

Advantages: Organizes code, avoids name conflicts, supports reuse and helps control access.

Create file Student.java:

package mypack;
public class Student {
  public void show() {
    System.out.println("Hello Student");
  }
}

Use in Demo.java:

import mypack.Student;
class Demo {
  public static void main(String[] args) {
    Student s = new Student();
    s.show();
  }
}
Output
Hello Student

Compile the package class first, then compile and run the class that imports it.

2. Access modifiers

Definition: Access modifiers decide where a class member can be used.

ModifierAccess
privateSame class only
defaultSame package
protectedSame package and subclasses in other packages, subject to access rules
publicAccessible wherever the class/member is accessible

Memory trick: Private = class; default = package; protected = package + subclass; public = broadest access.

3. Interface

Definition: An interface describes methods that an implementing class must provide.

  1. Declared using interface.
  2. Class uses implements.
  3. Supports abstraction.
  4. A class can implement more than one interface.
  5. Interface fields are public, static and final by default.
interface A {
  void show();
}
class Demo implements A {
  public void show() {
    System.out.println("Hello");
  }
  public static void main(String[] args) {
    new Demo().show();
  }
}
Output
Hello

4. Multiple inheritance using interfaces

Java does not allow a class to extend two classes. It can implement multiple interfaces.

interface A {
  void show();
}
interface B {
  void display();
}
class C implements A, B {
  public void show() {
    System.out.println("Show");
  }
  public void display() {
    System.out.println("Display");
  }
  public static void main(String[] args) {
    C c = new C();
    c.show();
    c.display();
  }
}
Output
Show
Display

5. Exception handling

Definition: Exception handling manages runtime problems so the program can respond instead of stopping unexpectedly.

Keywords: try – risky code; catch – handles an error; finally – cleanup code; throw – throws an exception; throws – declares possible exceptions.

Example with multiple catch:

class Demo {
  public static void main(String[] args) {
    try {
      int a = 10 / 0;
    }
    catch(ArithmeticException e) {
      System.out.println("Cannot divide by zero");
    }
    catch(Exception e) {
      System.out.println("Other error");
    }
  }
}
Output
Cannot divide by zero

Types: Checked exceptions are checked by the compiler and must be handled or declared. Unchecked exceptions happen at runtime and are not forced by the compiler.

Examples: IOException is checked; ArithmeticException and NullPointerException are unchecked.

UNIT IV

Multithreading and I/O

Thread concepts, lifecycle, synchronization, files, streams and strings.
5 & 8 MARKS
8 MARKS

1. Multithreading

Definition: Multithreading means running multiple threads concurrently in one program. A thread is a small unit of execution.

Advantages: Better responsiveness, useful CPU work, concurrent tasks and improved application structure.

Two ways: Extend Thread class or implement Runnable interface.

Using Runnable:

class MyTask implements Runnable {
  public void run() {
    System.out.println("Thread running");
  }
}
class Demo {
  public static void main(String[] args) {
    Thread t = new Thread(new MyTask());
    t.start();
  }
}
Output
Thread running

The run() method contains the task. start() asks Java to start a new thread and then run the task.

5 / 8 MARKS

2. Thread life cycle

Common thread states:

  1. New – Thread object is created.
  2. Runnable – Ready or running under the scheduler.
  3. Blocked – Waiting to get a lock.
  4. Waiting – Waiting for another thread or event.
  5. Timed waiting – Waiting for a fixed time.
  6. Terminated – Execution has finished.
In Java's official Thread.State, running is included in RUNNABLE.

Definition: Synchronization controls access to shared data so only one thread at a time enters a synchronized section protected by the same lock.

It helps prevent race conditions and incorrect updates.

5. File handling

Definition: File handling is used to create, read, write and manage files.

Java file I/O classes are mainly in java.io.

ClassUse
FileRepresents file/directory
FileReaderReads characters
FileWriterWrites characters
FileInputStreamReads bytes
FileOutputStreamWrites bytes
BufferedReaderEfficient text reading

Read a file using FileReader:

import java.io.*;
class Demo {
  public static void main(String[] args) {
    try {
      FileReader f = new FileReader("test.txt");
      int ch;
      while((ch = f.read()) != -1)
        System.out.print((char)ch);
      f.close();
    }
    catch(IOException e) {
      System.out.println("File error");
    }
  }
}
Example output (if file contains Hello)
Hello

FileReader reads one character at a time. -1 means end of file.

6. Stream classes

Definition: A stream is a flow of data between a program and a source or destination.

  • Input stream reads data into a program.
  • Output stream writes data out of a program.
  • Byte streams handle bytes.
  • Character streams handle text characters.

Examples: InputStream, OutputStream, Reader, Writer, FileInputStream and FileReader.

3. Event Delegation Model

Definition: Event Delegation Model is Java's way of handling user actions such as clicking a button, pressing a key or moving a mouse.

Three parts

  1. Event source: Component that creates the event, such as a button.
  2. Event object: Carries information about the event, such as ActionEvent.
  3. Event listener: Receives and handles the event, such as ActionListener.

Working

  1. User clicks the button.
  2. Button creates an event.
  3. Listener receives the event.
  4. Listener runs the required code.
import java.awt.*;
import java.awt.event.*;
class Demo extends Frame implements ActionListener {
  Button b = new Button("Click");
  Demo() {
    b.setBounds(80,80,100,40);
    add(b);
    b.addActionListener(this);
    setSize(300,200);
    setLayout(null);
    setVisible(true);
  }
  public void actionPerformed(ActionEvent e) {
    System.out.println("Button clicked");
  }
  public static void main(String[] args) {
    new Demo();
  }
}
Output after button click
Button clicked

6. MVC architecture

Definition: MVC means Model–View–Controller. It separates an interface into three parts.

  1. Model: Stores data and state.
  2. View: Displays the user interface.
  3. Controller: Handles user actions and updates the model.

Example – Login form: Model stores login data, View displays fields and button, Controller handles the button click and checks the input.

Advantages: Easy maintenance, clear organization, easier changes and separation of responsibilities.

9. Simple Swing login form

import javax.swing.*;
class Login {
  public static void main(String[] args) {
    JFrame f = new JFrame("Login");
    JLabel l = new JLabel("Username");
    JTextField t = new JTextField();
    JButton b = new JButton("Login");
    l.setBounds(30,30,100,30);
    t.setBounds(130,30,150,30);
    b.setBounds(100,90,100,30);
    f.add(l); f.add(t); f.add(b);
    f.setSize(330,200);
    f.setLayout(null);
    f.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
    f.setVisible(true);
  }
}

Output: A window showing a username label, input field and Login button.
