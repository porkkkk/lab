Set 1 — Permissions & Basic Linux

Files with read/write/execute permissions, date, calendar and message.

1. Display files with read, write and execute permissions

Aim: Show regular files that have all three permissions for the current user.

Program — save as perm_check.sh
#!/bin/bash
echo "Files with read, write, and execute permissions for the user:"
for file in *
do
    if [ -f "$file" ] && [ -r "$file" ] && [ -w "$file" ] && [ -x "$file" ]
    then
        echo "$file"
    fi
done
Run line by line
nano perm_check.sh
chmod +x perm_check.sh
./perm_check.sh

In Nano: type the program, press Ctrl+O, Enter, then Ctrl+X. -f regular file · -r read · -w write · -x execute.

Set 2 — AWK & Windows CMD

Count characters, words and lines; create and manage files in Windows.

1. AWK count — characters, words, lines

Aim: Count totals in a text file, using the format in your lab record.

Step 1 — create sample file
nano sample.txt

Type these three lines in Nano, then save with Ctrl+O, Enter and exit with Ctrl+X.

Hello students
Welcome to AWK scripting
Linux labs are easy
Step 2 — create count.awk
nano count.awk
BEGIN {
    lineCount = 0
    wordCount = 0
    charCount = 0
}
{
    lineCount++
    wordCount += NF
    charCount += length($0)
}
END {
    print "Total Lines       : ", lineCount
    print "Total Words       : ", wordCount
    print "Total Characters  : ", charCount
}
Step 3 — run
awk -f count.awk sample.txt

The record's sample output is 3 lines, 8 words and 51 characters. Character counting excludes newline separators.

Set 3 — Sorting & Text Commands

Sort numbers and use head, tail, sort and grep.

1. Sort numbers in ascending order

Aim: Read numbers from the user and display them from smallest to largest.

Program — save as sort_numbers.sh
#!/bin/bash
echo "Enter numbers (separated by space):"
read numbers
echo $numbers | tr ' ' '\n' | sort -n
Run line by line
nano sort_numbers.sh
chmod +x sort_numbers.sh
./sort_numbers.sh

Example input: 45 12 3 89 7. Output is 3, 7, 12, 45, 89 (one number per line).

Set 4 — Process & File Processing

Process commands and the text tools from your practical syllabus.

1. Process management commands

Aim: Display, stop and time processes.

Run in Linux Terminal
ps
sleep 100 &
ps

Find the process ID (PID) for the sleep 100 process in the output of ps, then use the real number in the next command.

kill PID

Replace PID with the actual number; do not type the word PID literally.

nohup sleep 30 &
nice -n 10 sleep 5
time ls

ps list processes · kill send a stop signal · nohup continue despite hangup · nice set scheduling niceness · time measure duration.

2. File-processing commands

Aim: Select columns, join lines, remove repeated lines and convert case.

Create sample and run commands
cat > users.txt <<EOF
alice:1001:Admin
bob:1002:Staff
carol:1003:Staff
bob:1002:Staff
EOF
head users.txt
tail users.txt
cut -d ':' -f1 users.txt
sort users.txt
sort users.txt | uniq
grep bob users.txt
tr 'a-z' 'A-Z' < users.txt
echo -e "x\ny\nz" > letters.txt
paste letters.txt <(cut -d ':' -f1 users.txt)
sed 's/Staff/Employee/g' users.txt
awk -F ':' '{print $1, $2}' users.txt

cut select field · paste join columns · uniq remove adjacent duplicates · tr change lowercase to uppercase · sed replace text · awk print chosen fields. The paste example uses Bash process substitution.

Redirection symbols
echo "Hello" > file.txt
echo "Again" >> file.txt
cat < file.txt
cat file.txt | sort

> overwrite/create · >> append · < read input from a file · | send output to another command.

Set 5 — Directory, Redirection & Editors

Create a directory, display its contents, and edit files.

1. Create a user-defined directory

Aim: Ask for a folder name, create it, and show its contents.

Program — save as directory.sh
#!/bin/bash
echo "Enter directory name:"
read name
mkdir -p "$name"
cd "$name" || exit 1
touch file1.txt file2.txt
echo "Directory contents:"
ls
Run
nano directory.sh
chmod +x directory.sh
./directory.sh

Enter a name such as MyFolder. The script creates the folder and two empty files, then lists them.

2. Input/output redirection and editors

Aim: Write/append to files and edit a text file.

Redirection commands
echo "Hello Linux" > file.txt
echo "Welcome" >> file.txt
cat file.txt
cat < file.txt
vi editor
vi notes.txt

Press i and type your text. Press Esc, type :wq, then press Enter to save and exit.

Emacs editor — if installed
emacs file.txt

In Emacs, save with Ctrl+X then Ctrl+S. Exit with Ctrl+X then Ctrl+C.

Quick memory: date = date/time · cal = calendar · echo = message · awk = count/process text · mkdir = create folder · dir/ls = list contents · grep = search · sort = arrange · ps = processes · vi = editor.
