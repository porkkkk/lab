UNIT 1 – Introduction to Artificial Intelligence

AI basics, machine learning, expert systems and model training
1. Artificial Intelligence (AI)
Meaning: Artificial Intelligence is a technology that makes computers perform tasks that normally need human intelligence.

Examples include learning, problem-solving, decision-making and recognising patterns.

Main features

  1. Learning: Learns from data.
  2. Reasoning: Makes decisions using information.
  3. Problem-solving: Finds solutions.
  4. Pattern recognition: Identifies repeated patterns.
  5. Automation: Performs tasks automatically.

Uses in cyber security

  • Detects spam emails.
  • Finds malware.
  • Detects unusual network activity.
  • Identifies fake login attempts.
  • Helps prevent online fraud.

Advantages

  • Works quickly.
  • Checks large amounts of data.
  • Finds threats automatically.
  • Reduces human work.

Limitations

  • Needs good-quality data.
  • Can make wrong predictions.
  • Some systems are expensive.
  • Attackers may try to fool AI.
Example: An AI system checks an email and identifies it as spam because it contains suspicious links.
Remember: AI = Learn + Think + Decide + Act.
2. Types of Machine Learning
Meaning: Machine Learning (ML) is a part of AI that allows computers to learn from data without being programmed for every single task.

A. Supervised Learning

  • Learns using labelled data.
  • The correct answer is already given.
  • Learns from examples.
  • Used for spam and malware detection.
Example: Emails are labelled Spam or Not Spam. The system learns to classify new emails.

B. Unsupervised Learning

  • Learns using unlabelled data.
  • No correct answers are given.
  • Finds hidden patterns and groups.
  • Used to find unusual network activity.
Example: Groups similar network traffic and identifies traffic that looks different.

C. Reinforcement Learning

  • Learns by trial and error.
  • Gets rewards for good actions.
  • Gets penalties for bad actions.
  • Improves decisions over time.
Example: A security system learns which actions help block attacks.
TypeEasy memory
SupervisedLearns with answers
UnsupervisedFinds patterns
ReinforcementLearns with rewards
3. Expert Systems and Data Mining

Expert System

Meaning: An Expert System is an AI program that uses stored knowledge and rules to make decisions like a human expert.

Main components

  1. Knowledge Base: Stores facts and rules.
  2. Inference Engine: Uses rules to make decisions.
  3. User Interface: Allows users to interact.
  4. Explanation Facility: Explains the decision.

Working: User gives information → System checks its knowledge base → Inference engine applies rules → System produces a decision → It may explain the result.

Example: A security expert system checks suspicious activity and suggests whether it may be an attack.

Data Mining

Meaning: Data Mining is the process of finding useful patterns and information from large amounts of data.

Steps: Collect data → Clean data → Select useful data → Find patterns → Analyse results → Use results for decisions.

Uses in cyber security

  • Finds unusual login patterns.
  • Detects fraud.
  • Identifies suspicious users.
  • Finds malware behaviour.

Difference: An Expert System makes decisions using rules and stored knowledge. Data Mining discovers useful patterns from data.

4. Training and Optimisation
Training means teaching a machine learning model using data. Optimisation means improving the model so that it gives better results.

Main steps

  1. Data Collection: Collect information.
  2. Data Cleaning: Remove errors and duplicate data.
  3. Data Preparation: Arrange data in a useful format.
  4. Feature Selection: Choose important information.
  5. Model Selection: Choose an ML algorithm.
  6. Training: Teach the model using training data.
  7. Testing: Check the model with new data.
  8. Evaluation: Measure its performance.
  9. Optimisation: Improve its performance.
  10. Monitoring: Check it after deployment.

Important terms

  • Dataset: Collection of data.
  • Feature: Useful information given to the model.
  • Training data: Data used to teach the model.
  • Testing data: Data used to check the model.
  • Accuracy: How often predictions are correct.
Example: A spam detection model learns from thousands of spam and normal emails and then checks new emails.
Remember the order: Collect → Clean → Prepare → Select → Train → Test → Evaluate → Improve.

UNIT 2 – Spam and Malware Detection

Classification algorithms, malicious software and detection
1. Support Vector Machine (SVM) for Spam Detection
Meaning: Support Vector Machine is a machine learning algorithm used to classify data into different groups.

For spam detection, it separates emails into Spam (unwanted or dangerous emails) and Ham (normal and useful emails).

Working

  1. Collect emails.
  2. Extract features such as words, links and sender details.
  3. Train the SVM model.
  4. SVM creates a decision boundary.
  5. New emails are checked.
  6. The model classifies them as Spam or Ham.

Important terms

  • Hyperplane: A boundary that separates groups.
  • Support Vectors: Data points closest to the boundary.
  • Margin: Distance between the boundary and the closest points.

Advantages

  • Good for classification.
  • Works with many features.
  • Can handle complex data using kernels.

Limitations

  • Training can be slow for large datasets.
  • Needs proper parameter selection.
  • Performance depends on data quality.
Example: An email containing suspicious links and common spam words may be classified as spam.
2. Naive Bayes Algorithm
Meaning: Naive Bayes is a machine learning algorithm based on probability. It predicts a class by calculating how likely it is.

Bayes theorem

P(A|B) = [P(B|A) × P(A)] / P(B)

Working

  1. Collect spam and normal emails.
  2. Extract words and features.
  3. Calculate probabilities.
  4. Check a new email.
  5. Calculate the probability of Spam and Ham.
  6. Select the class with the higher probability.

Advantages

  • Simple and fast.
  • Works well for text classification.
  • Requires less training time.

Limitations

  • Assumes features are independent.
  • May give poor results if that assumption is unsuitable.
  • Depends on training data.
Example: If an email contains words commonly found in spam emails, Naive Bayes may classify it as spam.
3. Malware and Its Types
Meaning: Malware is harmful software created to damage computers, steal information or disturb computer systems.

Main types

  1. Virus: Attaches itself to a file or program and spreads when the infected file runs.
  2. Worm: Spreads automatically from one computer to another.
  3. Trojan Horse: Looks like useful software but performs harmful actions.
  4. Ransomware: Locks or encrypts files and demands money.
  5. Spyware: Secretly collects user information.

Effects of malware

  • Steals personal information.
  • Damages files.
  • Slows down computers.
  • Gives attackers access.
  • Causes financial loss.

Prevention

  • Use updated antivirus software.
  • Avoid unknown links and attachments.
  • Download software from trusted sources.
  • Keep the operating system updated.
  • Take regular backups.
Example: Ransomware encrypts a user's files and demands payment to restore access.
Remember: Virus attaches, Worm spreads, Trojan hides, Ransomware locks, Spyware watches.
4. Decision Tree and Deep Learning for Malware Detection

Decision Tree

Meaning: A Decision Tree is a machine learning algorithm that makes decisions using questions and conditions.

Working: Collect malware and normal-file data → Extract file features → Train the tree → Check conditions → Follow branches → Predict whether a file is malicious or safe.

Example: If a file has suspicious behaviour and unusual permissions, the model may classify it as malware.

Advantages: Easy to understand, simple to use and fast for many tasks.

Limitations: Can overfit training data and may be less accurate for complex patterns.

Deep Learning

Meaning: Deep Learning is a type of machine learning that uses artificial neural networks with many layers to learn complex patterns.

Working: Collect large amounts of data → Prepare data → Give data to a neural network → Hidden layers learn patterns → Model predicts whether the file is malicious → Evaluate and improve.

Advantages: Learns complex patterns and can work with large datasets.

Limitations: Needs large amounts of data, high computing power and more training time.

Difference: A Decision Tree uses questions and branches. Deep Learning uses many layers of artificial neurons.

UNIT 3 – Network Security and Authentication Abuse

Network traffic, botnets, account attacks and protection
1. Network Anomaly Detection
Meaning: Network Anomaly Detection is the process of finding unusual activities in a computer network. It helps identify possible cyberattacks.

Working steps

  1. Collect network traffic.
  2. Study normal network behaviour.
  3. Select important features.
  4. Detect unusual activities.
  5. Generate an alert.
  6. Investigate the activity.
  7. Take security action.

Examples of unusual activity

  • Too many login attempts.
  • Sudden increase in network traffic.
  • Unknown devices connecting.
  • Unusual data transfers.

Types of detection

  • Signature-based: Finds attacks by matching known attack patterns.
  • Anomaly-based: Finds activities that are different from normal behaviour.

Advantages

  • Finds suspicious activities.
  • Helps detect unknown attacks.
  • Improves network security.
  • Provides early warnings.

Limitations

  • May generate false alarms.
  • Needs proper training data.
  • Requires continuous monitoring.
Example: If a computer normally sends a small amount of data but suddenly sends a huge amount, the system may generate an alert.
2. Botnets and Their Topologies
Meaning: A Botnet is a group of infected computers or devices controlled by an attacker.

The infected devices are called Bots or Zombies. The attacker controlling them is called the Botmaster.

Main parts

  1. Botmaster – controls the botnet.
  2. Bots – infected devices.
  3. Command and Control (C2) – system used to send commands.
  4. Victim – target of the attack.

Types of Botnet Topologies

A. Centralised Topology

  • All bots communicate with a central server.
  • The server sends commands.
  • Easy for attackers to manage.
  • If the central server is removed, communication may stop.

B. Peer-to-Peer (P2P) Topology

  • Bots communicate with one another.
  • No single central server is required.
  • More difficult to shut down.
  • Commands can spread through connected devices.

C. Hybrid Topology

  • Combines centralised and P2P methods.
  • Uses more than one communication method.
  • Can be more flexible.

Uses of botnets by attackers

  • DDoS attacks.
  • Sending spam emails.
  • Stealing information.
  • Spreading malware.
  • Performing online fraud.

Prevention

  • Update devices.
  • Use firewalls.
  • Use antivirus software.
  • Monitor unusual network traffic.
  • Remove infected devices.
Example: An attacker controls thousands of infected computers and makes them send requests to a website. This can cause a DDoS attack.
3. Machine Learning Algorithms for Botnet Detection
Meaning: Machine Learning algorithms can study network traffic and identify patterns that may indicate botnet activity.

Important algorithms

  1. Decision Tree: Uses conditions to classify network traffic.
  2. Random Forest: Combines many decision trees to improve predictions.
  3. SVM: Separates normal traffic and suspicious traffic.
  4. Naive Bayes: Uses probability to classify traffic.
  5. K-Means: Groups similar network activities and helps find unusual groups.
  6. Neural Networks: Learn complex patterns from network data.

Working steps

  1. Collect network traffic.
  2. Extract features such as IP address, packet size and traffic volume.
  3. Clean the data.
  4. Train the ML model.
  5. Test the model.
  6. Detect suspicious traffic.
  7. Generate alerts.

Advantages

  • Detects suspicious behaviour.
  • Can process large amounts of traffic.
  • Helps identify unknown patterns.
  • Supports automatic detection.
Example: An ML system detects that many devices are sending similar unusual requests to one server and identifies possible botnet activity.
4. Authentication Abuse and Its Prevention
Meaning: Authentication Abuse happens when attackers misuse login systems or stolen login details to access user accounts without permission.

Main types

  1. Brute Force Attack: Tries many passwords until the correct one is found.
  2. Credential Stuffing: Uses stolen usernames and passwords from other websites.
  3. Password Spraying: Tries a few common passwords against many accounts.
  4. Phishing: Tricks users into giving their login details.
  5. Session Hijacking: Steals or misuses a user's active login session.

Prevention methods

  • Use strong passwords.
  • Enable Multi-Factor Authentication.
  • Limit failed login attempts.
  • Use account lockout.
  • Monitor unusual login activity.
  • Avoid suspicious links.
  • Use secure sessions.
  • Educate users about phishing.
Example: An attacker uses passwords leaked from one website to try logging into users' accounts on another website.
5. Strong Passwords, Account Lockout and MFA

A. Strong Passwords

Meaning: A strong password is difficult for attackers to guess.
  • Uses uppercase letters.
  • Uses lowercase letters.
  • Contains numbers.
  • Contains special characters.
  • Is long and unique.
  • Is not based on personal information.
Example: River!Cloud72#Tree. Do not reuse the same password on different websites.

B. Account Lockout

Meaning: Account Lockout is a security method that temporarily blocks an account after too many failed login attempts.

Working: User enters a password → System checks it → Wrong attempts are counted → If the limit is reached, the account is locked → User waits or completes account recovery.

Advantages: Reduces repeated password guessing, protects accounts and helps stop brute-force attacks.

C. Multi-Factor Authentication (MFA)

Meaning: MFA is a security method that asks users to prove their identity using two or more different types of verification.

Three common factors

  1. Something you know – password or PIN.
  2. Something you have – phone or security key.
  3. Something you are – fingerprint or face.

Working: User enters a password → System asks for another verification → User enters an OTP or uses a fingerprint → System checks the details → Access is allowed if verification succeeds.

Advantages: Adds extra security, protects stolen-password accounts and reduces unauthorised access.

Remember: Authentication security = Strong Password + Lockout + MFA.

UNIT 4 – Account Reputation and Biometric Authentication

Identity checking, biometric methods and authentication measures
1. Account Reputation Scoring
Meaning: Account Reputation Scoring is a method of checking how trustworthy an account is by studying its past and present activities.

The system gives a risk score based on account behaviour.

Factors checked

  1. Login history.
  2. Device information.
  3. IP address.
  4. Login location.
  5. Failed login attempts.
  6. Unusual account activities.
  7. Previous security problems.

Working

  1. Collect account information.
  2. Study login behaviour.
  3. Check the device and location.
  4. Find unusual activities.
  5. Calculate the risk score.
  6. Allow, block or request extra verification.
Example: A user usually logs in from India. Suddenly, the account receives a login attempt from another country. The system may mark it as risky and request MFA.

Advantages

  • Detects suspicious accounts.
  • Helps prevent account takeover.
  • Improves login security.
  • Supports risk-based authentication.
2. Biometric Authentication
Meaning: Biometric Authentication is a security method that identifies a person using their physical or behavioural characteristics.

Types

A. Physical Biometrics

  • Fingerprint.
  • Face.
  • Iris.
  • Retina.
  • Voice features.

B. Behavioural Biometrics

  • Typing pattern.
  • Mouse movement.
  • Walking pattern.
  • Signature behaviour.

Working

  1. Capture biometric information.
  2. Extract important features.
  3. Create a digital template.
  4. Store the template securely.
  5. Capture new biometric information during login.
  6. Compare it with the stored template.
  7. Allow or reject access.

Advantages

  • Convenient.
  • Difficult to copy perfectly.
  • Reduces dependence on passwords.
  • Can provide fast authentication.

Limitations

  • Requires special hardware.
  • Can produce incorrect results.
  • Biometric data must be protected.
  • A person's biometric feature cannot easily be changed if stolen.
Example: A smartphone uses a fingerprint to unlock the device.
3. Keystroke Recognition
Meaning: Keystroke Recognition is a biometric method that identifies a person by studying their typing pattern. Different people type in different ways.

Important features

  1. Dwell Time: How long a key is pressed.
  2. Flight Time: Time between releasing one key and pressing another.
  3. Typing Speed.
  4. Typing Rhythm.
  5. Key Press Pattern.

Working

  1. User types during registration.
  2. System records the typing pattern.
  3. It creates a typing template.
  4. During login, the system records typing again.
  5. It compares the new pattern with the stored pattern.
  6. Access is allowed or rejected based on the result.

Advantages

  • Can work in the background.
  • Does not always need extra hardware.
  • Helps detect account misuse.

Limitations

  • Typing changes with tiredness or stress.
  • Keyboard and device changes affect typing.
  • May produce false results.
Example: A system checks how a user types their password and compares it with their usual typing rhythm.
4. Facial Recognition
Meaning: Facial Recognition is a biometric technology that identifies or verifies a person using their facial features.

Working steps

  1. Capture: Camera captures the face.
  2. Detection: System finds the face in the image.
  3. Alignment: Adjusts the face position.
  4. Feature Extraction: Finds important facial features.
  5. Template Creation: Creates a digital face representation.
  6. Comparison: Compares it with stored information.
  7. Decision: Accepts or rejects the person.

Important technologies

  • Viola-Jones: Face detection.
  • MTCNN: Face detection and alignment.
  • FaceNet: Face feature representation.
  • ArcFace: Face recognition.

Liveness Detection: Checks whether the face belongs to a real person rather than a photo, video or fake face.

Advantages

  • Contactless authentication.
  • Fast verification.
  • Easy to use.
  • Useful in security systems.

Limitations

  • Lighting affects results.
  • Camera quality matters.
  • May produce incorrect matches.
  • Privacy must be protected.
Example: A smartphone scans a user's face to unlock the device.
Remember: Capture → Detect → Align → Extract → Compare → Decide.
5. FAR, FRR and EER

These are important measures used to evaluate biometric authentication systems.

FAR – False Acceptance Rate

It means the system wrongly accepts an unauthorised person.

Example: A stranger is incorrectly allowed to unlock a phone.

FRR – False Rejection Rate

It means the system wrongly rejects an authorised person.

Example: The correct user is unable to unlock their phone.

EER – Equal Error Rate

It is the point where FAR and FRR are equal. A lower EER generally indicates better biometric performance.

TermEasy meaning
FARWrong person accepted
FRRCorrect person rejected
EERFAR and FRR are equal
Remember: FAR = False Acceptance; FRR = False Rejection.
6. Continuous Authentication
Meaning: Continuous Authentication is a security method that checks a user's identity continuously while they are using a device or system.

Normal login checks identity only at the beginning. Continuous authentication keeps checking behaviour during use.

Information checked

  • Typing speed.
  • Mouse movement.
  • Device behaviour.
  • Location.
  • User activity.
  • Other behavioural patterns.

Working

  1. User logs in.
  2. System records normal behaviour.
  3. It monitors the user during the session.
  4. It compares current behaviour with normal behaviour.
  5. It calculates the risk.
  6. If unusual behaviour is found, it may request verification or block access.

Advantages

  • Detects account misuse during a session.
  • Improves security.
  • Helps identify suspicious behaviour.

Limitations

  • Needs continuous monitoring.
  • May affect privacy.
  • Can produce false alarms.
  • Requires system resources.
Example: If someone else starts using an already-unlocked laptop, the system may detect a different typing pattern and ask for verification.

UNIT 5 – AI for Fraud Prevention

Fraud detection models, ensemble learning, cloud AI and evaluation
1. Fraud Detection Using Machine Learning
Meaning: Fraud Detection is the process of identifying dishonest or illegal activities. Machine Learning helps detect fraud by learning patterns from previous data.

Examples of fraud

  • Credit card fraud.
  • Online payment fraud.
  • Fake transactions.
  • Identity theft.
  • Banking fraud.

Important ML algorithms

  1. Logistic Regression: Predicts whether an activity is normal or fraudulent.
  2. Decision Tree: Makes decisions using conditions.
  3. Random Forest: Combines many decision trees.
  4. SVM: Separates normal and fraudulent activities.
  5. Gradient Boosting: Improves predictions step by step.
  6. Isolation Forest: Finds unusual activities.

Working steps

  1. Collect transaction data.
  2. Clean the data.
  3. Select useful features.
  4. Train the ML model.
  5. Test the model.
  6. Detect suspicious transactions.
  7. Generate alerts.
  8. Take action.

Advantages

  • Detects suspicious transactions quickly.
  • Processes large amounts of data.
  • Reduces manual work.
  • Helps prevent financial loss.
Example: If a customer usually makes small transactions but suddenly makes a very large payment from an unusual location, the system may mark it as suspicious.
2. Bagging Technique

Full form: Bootstrap Aggregating.

Meaning: Bagging is a machine learning technique that combines multiple models to improve prediction accuracy and reduce errors.

Working

  1. Collect the training dataset.
  2. Create different random samples from the dataset.
  3. Train separate models using these samples.
  4. Each model makes a prediction.
  5. Combine the predictions.
  6. Produce the final result.
Example: Random Forest uses bagging. It combines predictions from many decision trees.

Advantages

  • Reduces overfitting in many cases.
  • Improves stability.
  • Gives more reliable predictions.
  • Works well with decision trees.

Limitations

  • Needs more computing resources.
  • Can be harder to understand.
  • Requires training multiple models.
3. Boosting Technique
Meaning: Boosting is a machine learning technique that combines multiple weak models to create a stronger model.

A weak model is a model that performs only slightly better than random guessing.

Working

  1. Train the first model.
  2. Check its mistakes.
  3. Give more attention to incorrectly predicted examples.
  4. Train the next model.
  5. Repeat the process.
  6. Combine the models to produce the final prediction.

Types

  • AdaBoost.
  • Gradient Boosting.
  • XGBoost.

Advantages

  • Can provide high prediction accuracy.
  • Learns from previous mistakes.
  • Useful for complex prediction tasks.

Limitations

  • Training can take more time.
  • Can overfit if not controlled.
  • Needs careful parameter selection.
Example: A fraud detection model learns from transactions that earlier models classified incorrectly and improves its future predictions.

8. Fraud Detection Model Evaluation
Meaning: Model Evaluation is the process of checking how well a machine learning model performs.

It helps us understand whether the model correctly identifies fraudulent and normal transactions.

A. Accuracy

Accuracy tells us how many predictions are correct.

Accuracy = (TP + TN) / (TP + TN + FP + FN)

B. Precision

Precision tells us how many transactions predicted as fraud are actually fraud.

Precision = TP / (TP + FP)

C. Recall

Recall tells us how many actual fraud transactions the model successfully identifies.

Recall = TP / (TP + FN)

D. F1-Score

F1-score combines precision and recall into one measure.

F1 = 2 × (Precision × Recall) / (Precision + Recall)

E. Confusion Matrix

A Confusion Matrix is a table used to compare actual results with predicted results.

TermMeaning
TP – True PositiveFraud correctly identified as fraud
TN – True NegativeNormal transaction correctly identified as normal
FP – False PositiveNormal transaction wrongly identified as fraud
FN – False NegativeFraud wrongly identified as normal

Why evaluation is important

  • Measures model performance.
  • Finds prediction errors.
  • Helps compare algorithms.
  • Improves fraud detection.
  • Helps select a suitable model.
Important: Accuracy alone may be misleading when fraud cases are very rare. Precision, recall and F1-score are also important.
Remember: Accuracy = All correct; Precision = Correct fraud alerts; Recall = Fraud found; F1 = Balance of precision and recall.
