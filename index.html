UNIT 1 – INTRODUCTION TO AI FOR CYBER SECURITY

1. Artificial Intelligence in Cyber Security

⌄
Definition: Artificial Intelligence (AI) is a branch of computer science that helps computers perform tasks that normally need human intelligence. Cyber Security means protecting computers, networks, software and data from attacks.

AI is used in cyber security to find attacks, protect information and respond to threats automatically.

Important Points

  1. Threat Detection: AI finds cyberattacks quickly.
  2. Malware Detection: AI identifies harmful software like viruses and ransomware.
  3. Spam Detection: AI separates unwanted emails from normal emails.
  4. Fraud Detection: AI finds unusual bank transactions.
  5. Network Monitoring: AI continuously checks network activities.
  6. User Behaviour: AI studies normal user activities and finds unusual actions.
  7. Automatic Response: AI can block harmful IP addresses and isolate infected computers.
  8. Prediction: AI studies old attacks and identifies possible future threats.
Example: If a college account normally logs in at 9 AM but suddenly has 100 failed login attempts at midnight, AI can identify it as suspicious and alert the administrator.

Conclusion: AI makes cyber security faster, smarter and more effective.

  • Real-time monitoring.
  • Predictive analysis.
  • Reduced human effort.
  • Automatic response.
  • Better data protection.
Example: A bank uses AI to identify an unusual credit card transaction and block it before money is stolen.

3. Applications of AI in Cyber Security

⌄
Definition: AI applications in cyber security are the different ways AI is used to protect computers, networks and information.
  1. Malware Detection: Finds viruses, worms, ransomware and spyware by studying file behaviour and code patterns.
  2. Intrusion Detection System (IDS): Monitors network traffic and identifies unauthorized activities.

First Stage – Expert Systems

Expert systems were popular during the 1970s and 1980s. An expert system is a computer program that makes decisions using knowledge and rules given by human experts.

Main Components

  1. Knowledge Base: Stores facts, rules and expert knowledge.
  2. Inference Engine: Uses rules to make decisions.
  3. User Interface: Helps users communicate with the system.

5. Types of Machine Learning

⌄
Definition: Machine Learning (ML) is a part of AI that allows computers to learn from data and make decisions without writing separate instructions for every situation.

1. Supervised Learning

  • Uses labelled data.
  • The correct answer is already given.
  • The computer learns from examples.
  • It predicts answers for new data.
Example: Emails are labelled as Spam or Not Spam. The computer learns to identify new spam emails.

2. Unsupervised Learning

  • Uses unlabelled data.
  • No correct answer is given.
  • Finds hidden patterns.
  • Groups similar data together.
Example: Grouping network traffic and finding unusual traffic.

3. Semi-Supervised Learning

  • Uses both labelled and unlabelled data.
  • A small amount of labelled data is given.
  • A large amount of unlabelled data is also used.
  • Helps improve learning when labelled data is limited.
Example: Face recognition using a small set of labelled images and many unlabelled images.

4. Reinforcement Learning

  • Learns through actions.
  • Receives rewards for correct actions.
  • Receives penalties for wrong actions.
  • Improves future decisions.
Example: A security system learns the best action to stop suspicious activities.

1. Spam Detection Using Support Vector Machine (SVM)

⌄
Definition: Support Vector Machine (SVM) is a supervised machine learning algorithm used to classify data into different groups. In spam detection, SVM separates emails into Spam and Ham.
  • Spam: Unwanted or harmful emails.
  • Ham: Normal emails.

Working of SVM

  1. Collect Emails: Collect previously labelled spam and normal emails.
  2. Convert into Numbers: Convert email words and links into numerical features.
  3. Identify Features: Count spam-related words and links.
  4. Create Classes: Divide emails into Spam (+1) and Ham (-1).
  5. Find Boundary: SVM finds the best line or boundary to separate the two groups.
  6. Maximum Margin: It selects the boundary with the largest possible gap between the groups.
  7. Test New Email: A new email is given to the model.
  8. Final Result: The model identifies the email as spam or ham.
f(x) = wᵀx + b
  • x = Input features.
  • w = Weight.
  • b = Bias.

Decision: If f(x) is greater than 0 → Spam. If f(x) is less than 0 → Ham.

2. Spam Detection Using Naive Bayes

⌄
Definition: Naive Bayes is a supervised machine learning algorithm based on Bayes' Theorem. It uses probability to identify whether an email is Spam or Ham.

Why is it called Naive Bayes?

  • Bayes – Based on Bayes' Theorem.
  • Naive – Assumes that the features are independent of each other.
P(A|B) = [P(B|A) × P(A)] / P(B)
  • P(A|B) = Probability after seeing the evidence.
  • P(B|A) = Probability of evidence in a class.
  • P(A) = Prior probability.
  • P(B) = Evidence probability.

Working Steps

  1. Collect previously labelled emails.
  2. Divide emails into Spam and Ham.
  3. Calculate the probability of Spam and Ham.
  4. Read the new email.
  5. Find important words.
  6. Calculate the probability of each word.
  7. Calculate the Spam and Ham scores.
  8. Compare both scores and select the higher score.
Example: A new email contains "Win Free Gift". The system checks how often these words appear in spam and normal emails. If the Spam score is higher, the email is classified as Spam.

Advantages

  • Simple and easy to use.
  • Fast classification.
  • Works well with text data.
  • Requires less training time.
  • Useful for email filtering.

Conclusion: Naive Bayes uses probability, while SVM uses the best separating boundary to identify spam emails.

Objectives of Malware Analysis

  8. Improve future threat detection.

Main Methods

  • Static Analysis: Examining a file without running it.
  • Dynamic Analysis: Observing the file while it runs in a safe environment.
Example: A security analyst examines a suspicious file and discovers that it secretly steals passwords.

1. Network Anomaly Detection Techniques

⌄
Definition: Network Anomaly Detection is the process of finding unusual activities in a computer network using AI and Machine Learning. An anomaly means an activity that is different from normal behaviour.

Why is it needed?

  1. Detects unusual network traffic.
  2. Identifies unknown cyberattacks.
  3. Finds malware activities.
  4. Detects unauthorized access.
  5. Protects network resources.
  6. Monitors user behaviour.
  7. Reduces security risks.
  8. Provides alerts to administrators.

Types of Network Anomalies

1. Point Anomaly: A single unusual data point. Example: One packet with an abnormally large size.

2. Contextual Anomaly: An activity that is unusual in a particular situation. Example: High traffic at 3 AM from an internal server.

3. Collective Anomaly: A group of activities that becomes unusual together. Example: Coordinated DDoS attack traffic.

Main Detection Techniques

  1. Machine Learning: Learns normal network behaviour and identifies unusual activities.
  2. Deep Learning: Uses neural networks with multiple layers to identify complex attack patterns.
  3. Autoencoder: Learns normal network traffic. Unusual traffic produces a high reconstruction error.
  4. Hybrid AI: Combines two or more AI techniques to improve detection.
  5. Statistical Detection: Uses average values and standard deviation to find unusual traffic.
  6. Supervised Learning: Learns from labelled normal and attack traffic.
  7. Unsupervised Learning: Finds unusual patterns without labelled data.
  8. Semi-Supervised Learning: Uses mostly normal data with a small amount of labelled attack data.
Example: If a network normally receives 500 connections per minute but suddenly receives 50,000 connections, AI identifies the activity as unusual.

Conclusion: Network anomaly detection helps identify unusual network activities and protects systems from cyberattacks.

2. Detecting Botnet Topology

⌄
Definition: A botnet is a group of infected computers, mobile phones or other devices secretly controlled by a cybercriminal. The infected devices are called Bots or Zombies. The attacker is called the Botmaster.

Botnet topology means the communication structure between the botmaster and infected devices.

How does a botnet work?

  1. An attacker infects computers using malware.
  2. The infected computers become bots.
  3. The botmaster controls the infected devices.
  4. Commands are sent to the bots.
  5. The bots perform harmful activities.
  6. They may steal data, send spam or attack websites.
Example: Imagine 10,000 computers are infected with malware. A hacker sends one command to all computers to attack a website. This is a botnet attack.

Types of Botnet Topology

1. Centralized Topology

  • All bots communicate with one central server.
  • The botmaster controls the server.
  • Commands are sent through the central server.
  • Easy to understand and manage.
  • If the central server is removed, the botnet may stop working.

4. Securing User Authentication and Authentication Abuse Prevention

⌄
User Authentication: The process of checking whether a person is really the user who is trying to access a computer, application or network.

Types of Authentication

  1. Password-Based Authentication: Uses username and password.
  2. Biometric Authentication: Uses fingerprint, face or iris.
  3. Two-Factor Authentication (2FA): Uses two verification methods, such as password and OTP.
  4. Multi-Factor Authentication (MFA): Uses two or more verification methods.

What is Authentication Abuse?

Authentication abuse happens when an attacker tries to misuse or bypass the login system to enter an account without permission.

Types of Authentication Abuse

1. Brute Force Attack: The attacker tries many password combinations until the correct password is found.

Example: Trying hundreds of passwords on a college login page.

2. Credential Stuffing: The attacker uses stolen usernames and passwords from an old data leak to access other websites.

Example: Using a stolen social media password to access an email account.

3. Password Spraying: The attacker tries a few common passwords against many different accounts.

Example: Trying one common password against 100 college accounts.

4. Phishing: The attacker creates a fake login page to steal usernames and passwords.

Example: Sending a fake bank login link to a student.

5. Session Hijacking: The attacker steals a user's session information to access an already logged-in account.

Prevention Methods

  1. Use strong passwords.
  2. Enable two-factor authentication.
  3. Use multi-factor authentication.
  4. Limit repeated login attempts.
  5. Use CAPTCHA to stop automated login attempts.
  6. Lock accounts temporarily after repeated failures.
  7. Monitor suspicious login activities.
  8. Use AI to identify unusual login behaviour.

How AI Helps

AI studies login time, device information, location and failed attempts.

Example: If a user normally logs in from India but suddenly an unknown device tries to access the account from another country, AI can ask for additional verification.

Conclusion: Authentication abuse prevention protects accounts from unauthorized access by using strong security methods and AI monitoring.

⌄

  2. Device Information: Checks whether the device is known or new.

  4. Failed Login Attempts: Checks repeated wrong passwords.

  6. Location: Checks unexpected login locations.
  7. Previous Security Incidents: Checks past suspicious activities.

Working of Facial Recognition

  5. Authentication: The camera captures the face again.
  6. Comparison: The system compares the new face with the stored face template.
  7. Final Decision: If the match is correct, access is allowed. Otherwise, access is rejected.

5. Additional Important Topics – Unit 4

⌄

A. Three Factors of Authentication

  1. Something You Know: Password or PIN.
  2. Something You Have: Smart card or OTP device.
  3. Something You Are: Face or fingerprint.

Other useful factors:

  • Somewhere You Are – Location.
  • Something You Do – Typing behaviour.

B. Liveness Detection

Liveness Detection checks whether the face in front of the camera belongs to a real, live person rather than a photograph or fake video.

Types of attacks:

  1. Photo attack.
  2. Video replay attack.
  3. 3D mask attack.
  4. Deepfake attack.

Detection methods:

  • Ask the user to blink or turn their head.
  • Check skin texture.
  • Check 3D face depth.
  • Study natural face movement.
  • Check natural skin colour changes.

C. Face Recognition Algorithms

  • Viola-Jones: A classical method that uses Haar features and a cascade classifier to detect faces.
  • MTCNN: Uses multiple neural network stages to detect and align faces.
  • FaceNet: Creates numerical face representations called embeddings.
  • ArcFace: Improves the separation between different face identities.

D. Performance Metrics

  • FAR (False Accept Rate): The percentage of unauthorized users wrongly accepted.
  • FRR (False Reject Rate): The percentage of genuine users wrongly rejected.
  • EER (Equal Error Rate): The point where FAR and FRR are equal.

E. Continuous Authentication

Continuous Authentication means checking a user's identity throughout a session instead of checking only at login.

Example: A system continuously studies the user's typing behaviour after login.

1. Fraud Prevention with Cloud AI Solutions

⌄
Definition: Fraud Prevention with Cloud AI means using cloud computing, Artificial Intelligence and Machine Learning to identify and prevent fraudulent activities. Fraud means cheating or performing illegal activities to steal money or information.

Types of Fraud

  1. Account Takeover: An attacker gains unauthorized access to a user's account.
  2. Synthetic Identity Fraud: Criminals combine real and fake information to create a false identity.
  3. Payment Fraud: Unauthorized use of payment methods.
  4. E-commerce Fraud: Fraudulent activities during online shopping.
  5. Insurance Fraud: Submitting false insurance claims.
  6. Loan Fraud: Giving false information to receive a loan.

How Cloud AI Helps

  1. Collects large amounts of transaction data.
  2. Processes data using cloud systems.
  3. Uses machine learning algorithms.
  4. Identifies unusual transactions.
  5. Predicts possible fraud.
  6. Sends automatic alerts.
  7. Helps block suspicious transactions.
  8. Provides real-time fraud monitoring.
Example: A person normally spends ₹500 to ₹2,000 using a bank card. Suddenly, a transaction of ₹1,00,000 happens from an unusual location. AI identifies the transaction as suspicious and alerts the bank.

Advantages

  • Fast fraud detection.
  • Handles large amounts of data.
  • Real-time monitoring.
  • Reduces human work.
  • Improves security.
  • Helps prevent financial loss.

2. Machine Learning Algorithms for Fraud Detection

⌄
Definition: Machine Learning algorithms for fraud detection are used to study previous transactions and identify suspicious financial activities automatically.

Traditional systems use fixed rules. Machine Learning learns from old data and identifies new suspicious patterns.

Working Steps

  1. Data Collection: Collect transaction amount, date, time, location and payment details.
  2. Data Preparation: Clean and organize the collected data.
  3. Feature Selection: Select useful transaction information.
  4. Model Training: Train the ML algorithm using old transactions.
  5. Pattern Learning: Learn the difference between genuine and fraudulent transactions.
  6. Testing: Test the model with new transactions.
  7. Fraud Detection: Identify suspicious transactions.
  8. Alert: Inform the bank or security team.

Important ML Algorithms

  1. Logistic Regression: Predicts the probability of fraud.
  2. Decision Tree: Uses questions and rules to identify fraud.
  3. Random Forest: Combines multiple decision trees.
  4. SVM: Separates genuine and fraudulent transactions.
  5. XGBoost: Uses boosting to improve prediction accuracy.
  6. Isolation Forest: Finds unusual transactions without requiring every transaction to be labelled.
Example: A bank uses Random Forest to identify unusual credit card transactions.

3. Bagging Technique

⌄
Definition: Bagging means Bootstrap Aggregating. It is a machine learning technique that combines multiple models to improve the final result.

Working Steps

  1. Collect the original training data.
  2. Create multiple datasets using random sampling.
  3. Train separate models using each dataset.
  4. Each model makes its own prediction.
  5. Combine all predictions.
  6. Use majority voting for classification.
  7. Select the result with the highest number of votes.
Example: Suppose 10 decision trees check a bank transaction. 7 trees say Fraud and 3 say Genuine. Final result = Fraud.

Advantages

  1. Improves accuracy.
  2. Reduces errors.
  3. Reduces overfitting.
  4. Provides more stable results.
  5. Combines multiple models.

Popular example: Random Forest.

4. Boosting Technique

⌄
Definition: Boosting is a machine learning technique that combines multiple models one after another. Each new model tries to correct the mistakes made by the previous model.

Working Steps

  1. Train the first model.
  2. Check its prediction errors.
  3. Give more attention to incorrectly predicted data.
  4. Train the next model.
  5. Correct previous mistakes.
  6. Repeat the process.
  7. Combine the predictions.
  8. Produce the final result.
Example: A model checks 1,000 bank transactions and wrongly identifies 100 transactions. The next model gives more attention to those mistakes and tries to correct them. Another model then works on the remaining mistakes.

Advantages

  1. Improves prediction accuracy.
  2. Corrects previous errors.
  3. Finds complex patterns.
  4. Useful for fraud detection.
  5. Produces strong prediction models.

Popular Algorithms

  • AdaBoost.
  • Gradient Boosting.
  • XGBoost.
  • LightGBM.
  • CatBoost.

5. Difference Between Bagging and Boosting

⌄
BaggingBoosting
Models work independentlyModels work one after another
Uses random samplesFocuses on previous errors
Combines predictions using votingCombines improved predictions
Reduces varianceFocuses on reducing errors
Example: Random ForestExample: AdaBoost, XGBoost

Easy way to remember:

  • Bagging = Many models work separately and vote.
  • Boosting = Models work one by one and correct mistakes.

6. Analyse Data with IBM Watson and Jupyter Notebook

⌄
Definition: IBM Watson and Jupyter Notebook are tools used for data analysis, Artificial Intelligence and Machine Learning.

IBM Watson

IBM Watson is an AI platform developed by IBM. It provides AI and machine learning services.

Uses

  1. Data analysis.
  2. Machine learning.
  3. Natural Language Processing.
  4. Predictive analysis.
  5. Fraud detection.
Example: A bank uses IBM Watson to study old transactions and identify fraudulent activities.

Jupyter Notebook

Jupyter Notebook is an interactive tool used to write and execute Python code in separate cells.

Features

  1. Write Python programs.
  2. Perform mathematical calculations.
  3. Create tables.
  4. Create graphs.
  5. Analyse datasets.
  6. Build machine learning models.

Important Python Libraries

  • Pandas: Used to manage and analyse data.
  • NumPy: Used for numerical calculations.
  • Matplotlib: Used to create graphs.
  • Scikit-learn: Used to build machine learning models.

Data Analysis Steps

  1. Data Collection: Collect transaction information.
  2. Data Loading: Load a CSV file into Jupyter Notebook.
  3. Data Cleaning: Remove duplicate and incorrect data.
  4. Data Processing: Organize the information.
  5. Data Analysis: Find useful patterns.
  6. Data Visualization: Create graphs and charts.
  7. Model Training: Train a machine learning model.
  8. Prediction: Identify possible fraudulent transactions.
Example: A bank loads thousands of transactions into Jupyter Notebook. It uses Pandas to clean the data and Scikit-learn to train a fraud detection model. IBM Watson can provide cloud-based AI capabilities.

Conclusion: IBM Watson and Jupyter Notebook help analyse large amounts of data and improve fraud detection.
