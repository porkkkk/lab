1. Network Reconnaissance

Aim: To collect public information about the college website and check its route.

Algorithm — LOOK → TRACE → TEST

  1. Open terminal.
  2. Look up domain details.
  3. Trace the route.
  4. Test with ping.
  5. Write the actual output.
whois stc.ac.in
dig stc.ac.in
traceroute stc.ac.in
ping stc.ac.in

# Windows
nslookup stc.ac.in
tracert stc.ac.in
ping stc.ac.in
ipconfig
WHOIS = domain info; DIG = DNS info; traceroute = hops; ping = reply test.
