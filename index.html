UNIT I

Java Basics

1. Introduction to Java

Meaning: Java is a computer programming language. We use it to write programs, apps and software.

Important points:

  1. James Gosling and his team developed Java.
  2. It was first called Oak.
  3. It was renamed Java.
  4. Java was released in 1995.
  5. Java uses classes and objects.
  6. Java can run on different operating systems with a JVM.
  7. Java supports many threads.
  8. Java has tools to handle errors and protect programs.
Remember: WORA means “Write Once, Run Anywhere”.

How a Java program runs:

Program.java → javac compiler → Program.class (bytecode) → JVM → Output

The compiler changes Java code into bytecode. The JVM runs the bytecode.

8. Program to Find the Largest of Three Numbers

class Largest {
  public static void main(String[] args) {
    int a = 10, b = 25, c = 15;

    if(a >= b && a >= c) {
      System.out.println(a);
    }
    else if(b >= a && b >= c) {
      System.out.println(b);
    }
    else {
      System.out.println(c);
    }
  }
}
Output: 25

Explanation: First, the program checks whether a is the largest. If not, it checks b. If both are not largest, c is the largest. The program prints the largest number.

Classes and Objects

1. Class and Object

Class: A class is a plan used to make objects. Object: An object is made from a class.
  • A class has variables and methods.
  • Variables store information.
  • Methods do a task.
  • One class can make many objects.
  • Objects use the class methods and variables.
class Student {

  public static void main(String[] args) {

2. Declaring an Object and Reference Variable

A reference variable holds the reference used to find and use an object.
Student s;              // Declare reference
s = new Student();      // Make an object
Student a = new Student(); // Do both together
  • Student is the class name.
  • s is the reference variable.
  • new makes an object.
  • Use the reference to call methods and use variables.

3. Assigning One Object Reference to Another

Student s1 = new Student();
Student s2 = s1;
  • s1 points to an object.
  • s2 = s1 makes s2 point to the same object.
  • It does not make a second object.
  • A change made using s1 can be seen using s2.

4. Constructors and Constructor Overloading

Meaning: A constructor is a special part of a class. It gives starting values to an object when the object is made.

Points:

  1. Its name is the same as the class name.
  2. It has no return type.
  3. It runs when an object is made with new.
  4. It gives starting values to variables.
  5. It can take values as input.
  6. A class can have more than one constructor.

Types: A no-argument constructor has no input. A parameterised constructor takes input values.

Constructor overloading: Writing more than one constructor with different input lists.

class Student {
  int mark;

  Student() {
    mark = 0;
  }

  Student(int m) {
    mark = m;
  }

  void show() {
    System.out.println(mark);
  }

  public static void main(String[] args) {
    Student s1 = new Student();
    Student s2 = new Student(90);
    s1.show();
    s2.show();
  }
}
Output:
0
90

5. this Keyword

Meaning: this means the current object.
  • It is used to refer to the current object's variable.
  • It helps when a variable and input value have the same name.
  • It can call another method in the same class.
  • this() can call another constructor in the same class.
class Student {

Here, this.mark means the class variable. mark means the input value.

7. Inheritance

Meaning: Inheritance allows a child class to use the methods and allowed variables of a parent class.
  1. It saves time and code.
  2. It avoids writing the same code again.
  3. The old class is called the parent or superclass.
  4. The new class is called the child or subclass.
  5. Use the word extends.
  6. Java supports single, multilevel and hierarchical class inheritance.
class Animal {

class Dog extends Animal {

  public static void main(String[] args) {

  }

UNIT III

Packages, Interfaces and Exception Handling

1. Package

Meaning: A package is a folder-like group of related Java classes and interfaces.
  1. It keeps related classes together.
  2. It makes programs neat and easy to find.
  3. It helps avoid class-name clashes.
  4. It helps control access to classes and members.
  5. It helps reuse code.

Types: Built-in packages are provided by Java, such as java.util and java.io. User-made packages are created by the programmer.

2. Create and Use a Package

File 1 – Message.java

package mypack;

public class Message {
  public void display() {
    System.out.println("Hello Java");
  }
}

File 2 – Test.java

import mypack.Message;

class Test {
  public static void main(String[] args) {
    Message m = new Message();
    m.display();
  }
}
Output: Hello Java

Steps:

  1. Write package mypack at the top of the first file.
  2. Create a public class inside it.
  3. Save the file in a folder named mypack.
  4. Use import to bring the class into another file.
  5. Make an object and call its method.

Compile from the parent folder: javac mypack/Message.java, then javac Test.java, then run java Test.

4. Interface

Meaning: An interface is like a rule list. It tells a class which methods it must provide.
  1. Use the word interface to create it.
  2. A class uses implements to use an interface.
  3. It helps hide details and show required actions.
  4. A class can use more than one interface.
  5. This allows a class to follow more than one set of rules.
  6. Interface variables are public, static and final by default.
  7. Normal abstract methods are public and abstract by default.

5. Exception Handling

Meaning: An exception is a problem that happens while a program is running. Exception handling lets the program deal with the problem.

Examples: Dividing by zero, using a wrong array position and opening a missing file.

WordEasy meaning

class Demo {
  public static void main(String[] args) {

    catch(ArithmeticException e) {
      System.out.println("Math Error");

Completed

  2. catch handles the problem.
  3. More than one catch can be used.
  4. The first matching catch runs.
  5. finally is used for clean-up work.
  6. This helps the program handle errors in a better way.

UNIT IV

Threads, Files, Streams and Strings

1. Multithreading

Meaning: Multithreading means a program can work on more than one task at the same time.
  1. A thread is one path of work inside a program.
  2. Java can run many threads.
  3. Threads can work at the same time.
  4. Threads in one program share its memory.
  5. It helps a program stay active while another task is running.
  6. It can make better use of the computer's processor.
  7. It is useful in games, music players and network programs.

Example: A music player can play a song while downloading another file.

2. Create a Thread Using Runnable

Steps: Make a class, use implements Runnable, write run(), make a Thread object and call start().

class MyTask implements Runnable {
  public void run() {
    System.out.println("Thread is running");
  }
}
class Demo {
  public static void main(String[] args) {
    MyTask obj = new MyTask();
    Thread t = new Thread(obj);
    t.start();
  }
}
Output: Thread is running
  • Runnable is used to describe the task.
  • run() contains the work.
  • Thread makes a thread to do the work.
  • start() starts the new thread.
Remember: Use start() to start a new thread. Do not call run() directly if you want a new thread.

3. Thread Life Cycle

The thread life cycle means the different stages a thread passes through.
NEW → RUNNABLE → WAITING / BLOCKED → RUNNABLE → TERMINATED
  1. New: The thread object has been made.
  2. Runnable: The thread is ready to run or is running.
  3. Blocked: The thread is waiting to get a lock.
  4. Waiting: The thread is waiting for another action.
  5. Timed waiting: The thread waits for a set time, such as during sleep().
  6. Terminated: The work has finished.

In Java, ready and running are both shown as RUNNABLE in the official thread states.

5. Synchronization

Meaning: Synchronization controls how threads use shared data. It helps one thread at a time use a synchronized method on the same object.
  1. It controls access to shared data.
  2. It helps stop two threads changing the same data at the same time.
  3. It helps prevent wrong results.
  4. It uses an object lock.
  5. Other threads wait until the lock is free.

8. Read a File Using FileReader

Program:

import java.io.*;

class ReadFile {
  public static void main(String[] args) {
    try {
      FileReader r = new FileReader("data.txt");
      int ch;

      while((ch = r.read()) != -1) {
        System.out.print((char)ch);
      }

      r.close();
    }
    catch(IOException e) {
      System.out.println("File Error");
    }
  }
}

Explanation:

  1. Import java.io to use file classes.
  2. FileReader opens data.txt.
  3. read() reads one character.
  4. The loop continues while a character is found.
  5. -1 means the file has ended.
  6. The character is printed.
  7. close() closes the file.
Keep a file named data.txt in the program's working folder before running this program.

3. Event Delegation Model

Meaning: It is the way Java handles actions like clicking a button or pressing a key.

Three parts:

  1. Event source: The item where the action happens. Example: Button.
  2. Event object: Holds information about the action. Example: ActionEvent.
  3. Event listener: Waits for the action and handles it. Example: ActionListener.

How it works:

  1. The user clicks a button.
  2. The button creates an event.
  3. Java sends the event to the listener.
  4. The listener runs its actionPerformed() method.
  5. The program does the required work.
import java.awt.*;
import java.awt.event.*;

class Demo extends Frame implements ActionListener {
  Button b;

  Demo() {
    b = new Button("Click");
    add(b);
    b.addActionListener(this);

    setLayout(new FlowLayout());
    setSize(300, 200);
    setVisible(true);
  }

  public void actionPerformed(ActionEvent e) {
    System.out.println("Button Clicked");
  }

  public static void main(String[] args) {
    new Demo();
  }
}
Output after clicking: Button Clicked

6. Simple Login Form Using Swing

import javax.swing.*;
import java.awt.*;
import java.awt.event.*;

class Login extends JFrame implements ActionListener {
  JTextField user;
  JPasswordField pass;
  JButton b;
  JLabel result;

  Login() {
    setTitle("Login Form");
    setLayout(new FlowLayout());

    add(new JLabel("Username"));
    user = new JTextField(15);
    add(user);

    add(new JLabel("Password"));
    pass = new JPasswordField(15);
    add(pass);

    b = new JButton("Login");
    add(b);

    result = new JLabel("");
    add(result);

    b.addActionListener(this);
    setSize(250, 200);
    setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
    setVisible(true);
  }

  public void actionPerformed(ActionEvent e) {
    if(user.getText().equals("admin") &&
       new String(pass.getPassword()).equals("1234")) {
      result.setText("Login Successful");
    } else {
      result.setText("Invalid Login");
    }
  }

  public static void main(String[] args) {
    new Login();
  }
}

Explanation:

  1. Import Swing, AWT and event classes.
  2. Make a JFrame window.
  3. Add a username box.
  4. Add a password box.
  5. Add a Login button.
  6. Connect the button to ActionListener.
  7. Check the entered username and password.
  8. Show a success or error message.
This is only a simple exam example. Real login systems should not keep passwords as plain text.

8. MVC Architecture

Meaning: MVC means Model, View and Controller. It splits a program into three parts.
MODEL = DATA
↓
VIEW = WHAT THE USER SEES
↑
CONTROLLER = HANDLES USER ACTIONS
  1. Model: Keeps the data. Example: whether a box is ticked.
  2. View: Shows the data on the screen.
  3. Controller: Handles the user's action and updates the model.

Example: When a user clicks a checkbox, the controller handles the click, the model changes its value and the view shows the new value.

Advantages:

  • Keeps the program organised.
  • Makes changes easier.
  • Makes testing easier.
  • Separates data from the screen.
  • Helps maintain large programs.
